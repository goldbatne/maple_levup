### 체감 판정

- **A — 너무 넓음.** 좋은 스폰에서는 58～60초지만 나쁜 스폰에서는 136.61초까지 늘었다. 다음 전투를 찾는 공백이 가장 크고 광역 스킬 평균 적중도 가장 낮다.
- **B — 다소 조밀함.** 10킬은 가장 빠르지만 전투 비율 94.74%로 목표 관찰 범위 80～90%를 넘었다. 5마리 동시 인지는 연속 표본의 2.61～9.18%에서 반복됐고 평균 동시 인지도 가장 높다. 포지셔닝 공간은 남지만 판단 휴지기가 거의 없다.
- **C — 적정.** 10킬이 34.61～39.55초로 안정적이고 전투 비율 84.03%가 목표 리듬 안에 들어왔다. B보다 11.8%p의 전투 여백이 생기면서도 A보다 탐색 이동이 17.0%p 줄었다.

기본공격만 사용한 스트레스 회차에서도 B 25.00초, C 34.61초에 10킬을 완료했다. 둘 다 광역기가 없으면 막히지는 않았다. C는 해당 난수에서 340 피해를 받아 B의 204보다 높았지만 사망하거나 행동이 막히지는 않았다. 단일 표본의 받은 피해로 생존 밸런스를 확정하지 않는다.

광역기는 B에서 가장 효율적이었지만 C도 평균 1.00명을 적중해 의미가 있었다. A의 0.42명보다 높고 B의 과밀도보다는 낮으므로, C가 `광역기가 유용하지만 없다고 막히지 않는` 목적에 가장 가깝다.

### 포획 체감

포획률은 첫 획득 10%, 중복 3%, 천장 없음으로 유지했다. 첫 획득 기대 처치 수 10마리를 10킬 평균에 대응시키면 기하분포상 기대 체감 시간은 A 약 85초, B 약 26초, C 약 38초다. 실제 포획은 난수이므로 보장 시간이 아니다.

### 포탈·충돌·스폰·HUD

- C의 350타일, RectTileMap mode 1, 포탈 네 개와 스폰 사각형이 MapBuilder 구조 검증을 통과했다.
- C 서쪽 포탈을 런타임 임시 RoomTable에 원본 연결과 함께 주입해 `map003_p4c → map002` 이동을 실제 확인했다.
- A/B/C 목표 스폰 수는 모두 5로 유지했고 10킬 후 리필까지 확인했다.
- 시간 측정 중 포탈은 우발 이동을 막기 위해 잠갔고, 원본 데이터와 실서비스 RoomTable은 변경하지 않았다.
- PC 카메라 12.8×7.2에 대해 C는 25×14이므로 한 화면짜리 방이 아니다. 실제 화면에서 이동·몰이 공간과 상단 중앙 보스 HUD 여백이 남았다.
- 하단 SkillBar는 전투 중심을 가리지 않았다. 우상단 버튼은 북동쪽 풍경 일부를 가리지만 이번 전투 중심과 포탈 식별을 막지는 않았다.

## 두 번째 대표 유형 — 긴 통로/장애물형

### 선정

`map077 / 용암빛 지하 통로`를 골랐다.

- 원본이 28×16이고 W/N 포탈을 가진 실제 일반 사냥방이다.
- 바닥 사선과 녹색 단절부가 반복되는 긴 통로형이라, 평지에서 통했던 단순 외곽 절삭이 장애물형에서도 유효한지 확인하기 좋다.
- 원래 몬스터는 Lv64 드레이크라 Lv22의 전투력 차이가 지형 비교를 오염시킨다. 따라서 비교 세션에서만 빨간 달팽이 Lv5 ×5를 사용하고 실제 RoomTable/몬스터 데이터는 바꾸지 않았다.

### 후보와 90초 통제 비교

| 항목 | 원본 `map077` | 후보 `map077_p4c` |
|---|---:|---:|
| 타일 영역 / 면적 | 28×16 / 448 | 25×14 / 350 (78.1%) |
| 포탈 | W `(-13,1)`, N `(0,8)` | W `(-11,1)`, N `(0,6)` |
| 스폰 범위 | x -10..10, y -4..6 | x -8.5..8.5, y -3.5..4.5 |
| 첫 교전 | 0.01초 | 0.02초 |
| 90초 처치 | 1 | 0 |
| 전투 비율 | 71.79% | 68.55% |
| 탐색 이동 비율 | 15.74% | 8.95% |
| 평균 / 최대 동시 인지 | 1.455 / 4 | 1.314 / 4 |
| 무교전 공백 합계 | 25.23초 | 27.23초 |

후보는 탐색 이동은 줄였지만 전투 비율과 처치 수를 개선하지 못했다. 이 맵은 장애물 모티브와 통로 절단 때문에 `외곽 78% crop + 스폰 사각형 축소`만으로는 전투 접근성을 보장하지 않는다. 빨간 달팽이가 보여도 통로 반대편에 남는 구간이 있었고, 원본/후보 모두 90초에 10킬을 달성하지 못했다.

따라서 `map077_p4c`는 구조 비교용 후보일 뿐 채택안이 아니다. 통로형은 전체 크기보다 전투 가능한 연결 통로, 몬스터별 접근 가능 구역과 스폰 지점을 수작업으로 재배치한 뒤 다시 측정해야 한다. 같은 이유로 해안 `map054`도 통제 몬스터가 수면 너머에 생성되어 비교 대상에서 제외했다. 수면/절벽 맵은 안전 타일 기반 스폰 필터가 먼저다.

## 맵 유형별 압축 원칙

| 유형 | 권장 시작점 | 적용 원칙 |
|---|---|---|
| 넓은 평지/공터형 | 면적 70～80% | C의 75～85% 밴드를 기본으로 하되 탐색 이동이 계속 길면 B 수준을 별도 후보로 시험한다. |
| 일반 사냥터 | 면적 75～85% | 포탈 거리 10～20% 감소, 목표 스폰 수 유지, 전투 비율 80～90%를 관찰한다. |
| 장애물/절벽형 | 면적 85～100%부터 보수적으로 | crop보다 연결 통로와 안전 스폰 셀을 먼저 고친다. 장애물 반대편의 접근 불가 스폰을 검사한다. |
| 긴 통로형 | 일률 면적 비율 없음 | 외곽 절삭보다 빈 구간 단축, 굴곡 수 감소, 전투 포켓 재배치가 우선이다. |

| 보스방 | 원형 유지 우선 | 패턴 회피, 돌진, 투사체, 상단 HUD 공간을 보존한다. 축소는 보스별 별도 테스트만 허용한다. |

전체 맵에 같은 비율을 적용하면 해안선·절벽·건물·통로의 의미가 깨지고, 겉보기 면적은 줄어도 몬스터가 장애물 건너편에 남아 실제 이동 공백이 늘 수 있다. Bounding Box와 좌표 오프셋은 자동화할 수 있지만 랜드마크, 안전 스폰 셀과 전투 포켓은 수작업 판정이 필요하다.
