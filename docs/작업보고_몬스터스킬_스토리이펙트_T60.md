# T60 첫 지역 몬스터 스킬 — 설정 기반 창작 이펙트

> **폐기·미적용 시안 (2026-09-07).** 전직 스킬의 아트 디자인과 맞지 않는 굵은 픽셀 문양으로 판정했다.
> 아래 RUID와 레시피는 현재 `SkillTable.csv`에서 모두 제거했으며, 첫 지역 5종은 T59 이전 단일 이펙트로 복구했다.
> SVG·PNG는 실패 원인과 재사용 금지 근거를 남기기 위한 아카이브일 뿐 게임에서 사용하지 않는다.

## 당시 시안의 결론 (현재 폐기)

T59에서 시험한 공용 별·링·화살 겹치기는 전직 스킬급 연출로 보기 어려웠다. 해당 조합은 폐기했다.
이번 작업은 **공식 스킬팩 이펙트를 사용하지 않고**, 몬스터 설정에서 색·형태·동작의 소재만 뽑아
프로젝트 전용 스프라이트를 직접 그린 뒤 시간차·크기·이동을 조합하는 방식으로 바꿨다.

## 설정에서 가져온 소재

- 달팽이: 메이플 아일랜드·빅토리아 아일랜드의 약한 토착 몬스터이며, 껍질을 던지던 옛 이야기에서
  `풀잎 껍질 회오리`를 설계했다. 출처: <https://maplestorywiki.net/w/Snail>
- 파란 달팽이: 달팽이보다 크고 단단한 변종이라는 설명에서 물결이 겹쳐지는 방벽을 설계했다.
  출처: <https://maplestorywiki.net/w/Blue_Snail>
- 빨간 달팽이: 파란 달팽이가 전직해 붉어졌다는 섬의 전승과 더 빠르고 강하다는 설명에서
  붉은 껍질의 다단 잔상 돌진을 설계했다. 출처: <https://maplestorywiki.net/w/Red_Snail>
- 슬라임: 점액의 점성으로 뛰어오르고 사과향이 난다는 설명에서 탄성 호·착지 점액·향기 반짝임을
  한 문양으로 만들었다. 출처: <https://maplestorywiki.net/w/Slime>
- 마노: 가장 오래된 달팽이, 아침 이슬과 잎, 소원을 들어준다는 무지개빛 껍질 전승을 합쳐
  보스용 원형 문양을 설계했다. 출처: <https://maplestorywiki.net/w/Mano>

## 연출 레시피

- 달팽이: 충전 껍질 `42bd...` → 전방 회오리 `5dc9...` → 충돌 파열 `4014...`
- 파란 달팽이: 응축 껍질 `3d6f...` → 십자 방벽 `1a2c...` → 물결 수호 `b621...`
- 빨간 달팽이: 가속 껍질 `ead4...` → 붉은 잔상 `5fc7...` → 유성 충돌 `59b7...`
- 슬라임: 점액 압축 `c224...` → 탄성 도약 `9177...` → 착지 파열 `799e...`
- 마노: 이슬 궤도 `18fa...` → 잎 파동 `5bad...` → 무지개 소원 `ecc6...`

모든 스킬이 서로 다른 3개 그림을 사용한다. 같은 RUID를 크기만 바꿔 반복하는 T60 초기 시안도 폐기했다.

## 검증

- 정적 콘텐츠 검증: `badLayerRecipes=[]`
- 첫 지역 레이어 수: `3 / 3 / 3 / 3 / 3`, 합계 15
- 검증기는 각 스킬의 3개 RUID가 모두 서로 다른지와 정확한 순서까지 검사한다.
- 방향 반전: 짝수 번째 테스트에서 `flipX=true`, 오류 없음
- 빌드 로그: 오류 0건
- 런타임 로그: 신규 오류 0건
