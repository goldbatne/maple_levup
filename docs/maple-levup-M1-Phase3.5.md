# Maple Levup — Phase 3.5 포획 정책·Trait 정리

> 2026-09-16 기준. Phase 4 맵 축소 전에 포획 보상과 랜덤 추첨 계약을 단순화한다.

## 확정 계약

### Trait

- 신규 랜덤 전투(`phase1_random_combat_enabled=1`)에서 Trait를 사용하지 않는다.
- 모든 보유 액티브 종의 공급 Weight는 1.0이다.
- 모든 액티브/방어 효과의 Trait 배율은 1.0이다.
- TraitWindow와 열기 버튼을 함께 숨겨 중앙 배경·마스크를 남기지 않는다.
- `TraitTable`, `selected_trait`, 저장 필드와 기존 코드는 삭제하지 않고 레거시 모드용으로 보존한다.
- 다른 빌드/특성 시스템으로 대체하지 않는다.

### 포획

| 상태 | 확률 | 종별 천장 | 획득 결과 |
|---|---:|---:|---|
| 해당 스킬 0장 | 10% | 20킬 | 첫 획득, OwnedSkills 1장 |
| 해당 스킬 1～4장 | 3% | 40킬 | 중복 강화 1장 추가 |
| 해당 스킬 5장 | 판정 없음 | 누적 없음 | 만작 유지 |

- 데이터 키: `first_capture_rate`, `first_capture_pity`, `duplicate_capture_rate`, `duplicate_capture_pity`.
- `SpeciesKills[monster_id]`는 현재 획득 단계의 천장 카운터로 재사용하고 성공 시 0으로 초기화한다.
- 현재 몬스터별 `capture_modifier`는 기존 확장 지점으로 보존하며 기본값은 1.0이다.
- 레거시 플래그 OFF 경로의 기존 3%+LUK 및 40킬 구조는 삭제하지 않는다.

### 중복과 랜덤 슬롯

- 중복 보유 1～5장의 스킬 계수는 기존 ×1.0 / ×1.2 / ×1.4 / ×1.6 / ×1.8을 유지한다.
- 보유 장수는 공급 Weight에 영향을 주지 않는다. 1장만 있어도 복원 추출로 A/A/A/A/A가 가능하다.
- 최대 5칸, 5초마다 빈칸 하나 공급, 중복 허용, 성공 사용 슬롯만 소비, 개별 쿨다운 없음, 직접 장착 없음은 Phase 1 계약을 그대로 유지한다.

### 패시브와 장비

- 패시브 35종은 신규 모드에서 포획 판정·천장 누적·획득 알림을 만들지 않는다.
- 기존 OwnedSkills 개수, 아이콘, SkillTable 행과 레거시 기능은 보존한다.
- 신규 보유 스킬 UI에서는 패시브를 숨긴다.
- LUK 전용 장비 7종은 Phase 3의 0효과 상태를 유지하며 임의 효과를 추가하지 않는다.

## Maker 검증 결과

- 빌드 오류 0건. 기존 모델 경고 2건은 이번 변경과 무관하다.
- 액티브 67종, 패시브 35종으로 확인했다. 신규 모드에서는 패시브 35종을 추첨·포획·컬렉션 표시에서 제외한다.
- 공급 후보 66종을 대상으로 Weight 264회와 효과 배율 66회를 검사해 모두 정확히 1.0이었다.
- 100회 표본 추첨에서 보유 5종 모두 등장했고, 특정 Trait 선택값은 결과에 관여하지 않았다.
- 첫 획득은 10%·20킬 천장, 중복은 3%·40킬 천장, 5장은 무판정으로 실행됐으며 성공 시 종별 실패 카운터가 0으로 초기화됐다.
- 보유 1～5장 계수는 1.0 / 1.2 / 1.4 / 1.6 / 1.8이었다. 보유 1장과 5장의 공급 Weight는 모두 1.0이었다.
- 보유 스킬 1종으로 26.5초 후 동일 스킬 5칸 충전, 한 칸 소비 직후 4칸 유지, 5.5초 후 5칸 복구를 확인했다.
- 같은 스킬 두 칸은 레거시 쿨다운 값이 남아 있어도 연속 사용됐고 각 슬롯만 독립 소비됐다.
- 저장 재접속에서 Lv21, EXP 253, 달팽이 스킬 1장, 달팽이 진행도 29가 복원됐다.
