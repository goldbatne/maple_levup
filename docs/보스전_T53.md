# 보스전 공통 규격 (T53)

## 적용 범위

현재 `RoomTable.room_type=boss`인 6방 전부에 공통 적용한다.

| 방 | 보스 | HP (×10) | 확정 보상 |
|---|---|---:|---|
| `r_05` | 머쉬맘 | 6,230 | 머쉬맘의 균형 반지 |
| `r_job_01` | 히어로 | 7,940 | 직업 스킬 5종 (기존 확정 보상) |
| `r_15` | 스텀피 | 9,990 | 스텀피 묘목 |
| `r_25` | 파우스트 | 7,940 | 파우스트 꼬리 부적 |
| `r_045` | 셰이드 | 14,780 | 그림자 부적 |
| `r_055` | 주니어 발록 | 18,200 | 주니어 발록 영혼석 |

히어로는 포획·드랍 몬스터가 아니라 전직 시험 NPC라 전용 장비를 새로 만들지 않았다.
격파 시 `npc_skill_ids` 5종을 확정 지급하는 기존 보상 규칙을 유지한다.

## 전투 규칙

- 새 보스가 실제로 스폰된 순간부터 **5분(300초)** 카운트한다.
- 다른 플레이어가 들어와도 방에 전투 중인 플레이어가 남아 있으면 살아 있는 보스의 시간은 초기화하지 않는다.
- 방이 완전히 비면 남은 보스를 보상 없이 제거하고 전투 상태를 비운다. 다음 입장은 **전체 HP·300초**의 새 전투다.
- 상단 중앙의 폭 **600px** HUD에 보스 이름, 현재/최대 HP, 남은 `MM:SS`를 표시한다.
- 정상 격파 시 HUD를 닫고 기존 EXP·포획·클리어 보상을 지급한다.
- 시간초과 시 보스를 보상 없이 제거하고 연결된 직전 방으로 퇴장시킨다.
- 연결이 없는 `r_job_01`은 시작 마을로 돌려보낸다.
- 보스 전용 장비(`drop_from`이 해당 보스인 아이템)는 **100%** 드랍한다.
  공용 빨간 포션(`drop_from=*`)은 기존 확률과 LUK 배율을 유지한다.
- 이미 장비 보유 상한에 닿았으면 바닥에 생성하지 않는다. 주워도 버려지는 가짜 드랍을
  만들지 않기 위한 기존 규칙이다.

## 구현 소유권

- `RoomSpawner.mlua`: 보스전 시작·HP/타이머 동기화·시간초과 판정·퇴장
- `RoomMonster.mlua`: 보상 없는 시간초과 제거 경로
- `PlayerHud.mlua` + `ui/PlayerHud.ui`: 상단 HUD 표시
- `ItemDrop.mlua`: 보스방 전용 장비 확정 판정
- `GameBalance.csv`: `boss_hp_multiplier=10`, `boss_time_limit_seconds=300`

## 검증 상태

`node docs/tools/verify-content-coverage.cjs` 정적 검증 통과:

- 보스방 6 / 전용 보상 누락 0
- HP 배율 10 / 제한시간 300
- BossHud 엔티티 6 / UI 바인딩 6개 정상
- 타이머·시간초과·확정 드랍 배선 확인

Maker 런타임 실측 완료(`r_055`, 2026-08-30):

- Refresh 뒤 빌드 로그 **0건**
- 입장 시 상단 `BOSS 주니어 발록` / `18,200 / 18,200` / `04:49` 표시
- 서버에서 HP를 5,000 낮추자 화면이 `13,200 / 18,200`으로 동기화
- 타이머를 만료 상태로 만들어 `r_055 → r_054` 퇴장 및 HUD 숨김 확인
- HP `13,200 / 18,200` 상태에서 방을 완전히 비우자 `[보스전 리셋]` 로그와
  `BossActive=false / HP=0 / 시간=0`을 확인했고, 재입장 직후 **`18,200 / 18,200 · 299.401초`**로 새로 시작했다.
- 상단 HUD를 920px → **600px**로 줄인 뒤 메뉴 영역과 겹치지 않고 이름·HP·시간이 모두 보이는 화면을 확인했다.
- 우측 `스탯·스킬·가방` 버튼도 각각 **152px → 112px**로 줄이고 오른쪽에 모았다.
  버튼 사이는 12px, 보스바와 메뉴 묶음 사이는 70px 논리 간격이다.
- 전용 아이템 굴림 `0.929`에도 확률 `1.000 [보스 전용 확정]`으로 드랍,
  `주니어 발록 영혼석 0 → 1` 획득 확인
- 테스트로 변한 영혼석·EXP·포획 천장 카운터는 `0 / 9,974 / 0`으로 저장 복구 후 Play 종료

한 보스방의 공통 `RoomSpawner` 경로를 실측한 것이다. 나머지 5방도 같은 코드와
`room_type=boss` 판정을 사용하며 정적 검증에서 전용 보상 누락 0을 확인했다.
