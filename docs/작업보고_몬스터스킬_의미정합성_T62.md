# T62 몬스터 스킬 의미 정합성 전수 교정

## 결론

메이플 아일랜드부터 노틸러스까지 몬스터 스킬 30종을 전수 확인했다. 액티브 23종은
`이름 → 공격 주체 → 형상 → 움직임 → 대상 방식`이 한 문장으로 이어지는지 확인했고,
보유형 패시브 7종은 시전 이펙트가 전혀 없도록 유지했다.

T61에서 품질만 보고 가져온 직업 스킬 클립 가운데 몬스터와 맞지 않는 검·창·사슬·화살 형상은
제거했다. 단순히 색을 바꾸지 않고 몬스터의 몸과 이야기에서 소재를 다시 뽑았다.

## 창작 기준

| 설정 단서 | 전투 동작 | 화면에서 반드시 보여야 하는 형상 |
|---|---|---|
| 달팽이의 단단한 껍질 | 몸통 박치기·껍질 돌진·방어 | 충돌 파열, 껍질, 원형 방벽 |
| 버섯의 포자와 거대한 몸 | 살포·지면 충격 | 흩어지는 포자, 지면 파동 |
| 페리온의 바위·고목·뿌리 | 경화·도끼 휘두르기·속박 | 바위 조각, 도끼날, 뿌리 |
| 언데드와 원혼 | 뼈 무덤·냉기·심연 | 뼈, 차가운 영기, 어둠 장막 |
| 커닝시티의 옥토퍼스 | 먹물 폭발 | 검보라 먹물과 방울 |
| 노틸러스의 해양 생물·리본돼지 | 리본 돌진·별가시 회전 | 리본 궤적, 불가사리 몸체와 물결 |

## 실제 교정

| 스킬 | 문제였던 연출 | 최종 연출 |
|---|---|---|
| 붉은 껍질 돌진 | 화면에 거의 잡히지 않는 범용 클립 | 붉은 등껍질과 전방 가속 잔상 |
| 암석 피부 | 고목 방어용 통나무 조각 | 몸 주위를 닫는 바위 파편 |
| 도끼 휘두르기 | 검을 사용하는 직업 베기 | 박힌 도끼 두 자루의 교차 궤적 |
| 어둠의 뿌리 | 마법 사슬 | 땅에서 솟는 보라색 뿌리 |
| 뼈 무덤 | 창 찌르기 또는 무연출 | 지면에서 방사형으로 솟는 뼈 |
| 먹물 폭발 | 붉은 검격·어둠 발톱 | 검보라색 먹물 덩어리와 튄 방울 |
| 심연의 장막 | 세 번째 레이어의 붉은 검격 | 어둠 응축·심연 파동·검은 장막 |
| 리본 돌진 | 주황색 화살형 돌진 | 위아래로 휘날리는 분홍 리본 궤적 |
| 별가시 회전 | 푸른 검 회전·흰 창 | 불가사리 몸체가 회전하는 별가시 파동 |

달팽이 충돌, 푸른 껍질, 포자, 머쉬맘 충격, 와일드보어 돌진, 파이어보어 화염,
스텀피 생기탄, 슬라임 탄성, 페어리 마법가루, 다크 스텀프 밑동, 파우스트 저주,
주니어 레이스 냉기, 주니어 발록 화염은 이름·설정·대상 방식이 일치해 유지했다.

## 검증

- 정적 검사: 몬스터 스킬 30종, 액티브 무연출 0, 패시브 연출 잔여 0,
  잘못된 레이어 레시피 0, 잘못된 RUID 0.
- Maker 서버 경로에서 교정 대상의 `PlayCast`를 직접 실행했다.
- 화면 확인: 붉은 등껍질, 바위 갑옷, 도끼, 뿌리, 뼈 무덤, 먹물, 리본, 불가사리 형상이
  각각 이름대로 표시되고 생성·종료 로그가 쌍으로 남았다.
- 빌드 오류 0. 기존 모델 경고 2건(`mano` InputSpeed, `bowmaster` AvatarAttackPlayRate)은
  이번 스킬 데이터 교정 이전 시각의 기존 경고이며 신규 오류가 아니다.

전용 원본과 RUID 대응은 [T62 리소스 표](art/monster-skill-effects/t62/README.md)에 기록했다.
