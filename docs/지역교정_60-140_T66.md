# Lv60~140 지역·보스 교정 T66

> 기준: 2026-09-09 · 지역 소속 교차 검증과 대표 방 타일 보강

## 교정 결론

노틸러스 갑판에 있던 주니어 발록은 지역 서사와 맞지 않았다. 주니어 발록을 슬리피우드 최종 보스로 옮기고, 노틸러스에는 해안 지역 보스로 자연스러운 킹크랑을 배치했다. 킹크랑은 과거 플로리나 비치 몬스터로 기록되어 있으며 보스 분류도 확인된다.

- 킹크랑 자료: https://maplestorywiki.net/w/King_Clang
- 플로리나 비치 몬스터 기록: https://maplestorywiki.net/w/Florina_Beach
- 킹크랑 과거 드랍 목록: https://www.hidden-street.net/kms/monster/%ED%82%B9%ED%81%AC%EB%9E%91

## 몬스터·보상 변경

| 위치 | 변경 후 | 역할 |
|---|---|---|
| `r_055` | 킹크랑 Lv60 | 노틸러스 최종 보스 |
| `r_074` | 타우로마시스 5마리 | 슬리피우드 수문장 일반전 |
| `r_075` | 주니어 발록 Lv70 | 슬리피우드 최종 보스 |

킹크랑은 공식 MSW 리소스 검색에서 확인한 애니메이션 클립으로 모델을 구성했다. 포획 스킬은 집게 공격과 파도를 결합한 `왕게의 집게 파도`이며, 장비 드랍은 과거 실제 드랍 목록의 `노란 우산`(MapleStory item ID `1302016`)을 사용한다. UI 아이콘은 해당 아바타 아이템의 `thumbnail://` RUID를 사용한다.

## Maker 재검증 결과

- `r_055`: 킹크랑 본체와 보스 HUD가 정상 표시됐다. HP는 `21,620/21,620`, 제한 시간은 300초로 시작했다. 처음 본체가 보이지 않았던 것은 리소스 실패가 아니라 Lv119 테스트 캐릭터의 자동 공격으로 약 11초 만에 처치된 뒤 확인했기 때문이다.
- `r_075`: 주니어 발록 본체와 보스 HUD가 정상 표시됐고 HP는 `25,040/25,040`이었다. `map074`로 나갔다가 다시 들어오자 HP가 전부 회복되고 제한 시간이 약 299초로 다시 시작했다.
- `map077`: 용암 균열 30칸이 화면에 표시됐다. 플레이어를 `(-11.3, -1.0)`에 두고 오른쪽 입력을 1.4초 주어도 위치가 변하지 않아 통행 차단을 확인했다.
- `map085`: 달빛 정원 35칸이 화면에 표시됐다. 같은 입력에서 플레이어가 `(-2.3, -1.0)`에서 `(0.47, -1.0)`까지 이동해 정원 타일 통과를 확인했다.
- `map13a`: 오아시스 물 43칸이 화면에 표시됐다. 플레이어가 `(0.3, -1.0)`에서 `(0.99, -1.0)`까지만 이동한 뒤 추가 오른쪽 입력에도 `(0.99, -1.0)`에 머물러 물 경계 통행 차단을 확인했다.
- Build Console의 이번 실행 신규 오류는 0건이다. 여섯 정적 검증 명령도 모두 종료 코드 0으로 통과했다.

`GameDataVerify.mlua`의 구형 검사 규칙도 현재 데이터에 맞췄다. 전직 보스방의 단방향 귀환은 일반 방 왕복 검사에서 제외하고, 실제 장비 슬롯인 `pants`·`shoes`·`cape`를 허용한다. 파일 변경은 반영됐지만 현재 Maker 세션은 이전 스크립트 캐시를 계속 사용했으므로 다음 Maker 완전 재실행에서 로그 정리를 다시 확인한다.
