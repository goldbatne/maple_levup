# T67 — Lv141~180 지역 확장

> 작성: 2026-09-09 · 검증 완료: 2026-09-10 · 상태: 구현·정적·Maker 런타임 검증 완료

## 목표

기존 8방 분기형 지역 규격을 유지해 무릉도원, 미나르숲, 시간의 신전, 지구방위본부를 추가한다. 각 지역은 일반 몬스터 4종과 보스 1종, 포획 스킬 액티브 3종·패시브 2종, 몬스터별 장비 1종, 전용 바닥 4종을 가진다.

## 지역과 연결

| 지역 | 레벨 | 해금 | 보상방 열쇠 | 보스 전방 스탯 |
|---|---:|---:|---|---:|
| `area_15` 무릉도원 | 141~150 | Lv140 | 키메라 스킬 | 715 |
| `area_16` 미나르숲 | 151~160 | Lv150 | 태륜 스킬 | 765 |
| `area_17` 시간의 신전 | 161~170 | Lv160 | 마뇽 스킬 | 815 |
| `area_18` 지구방위본부 | 171~180 | Lv170 | 도도 스킬 | 865 |

각 지역은 `1 → 2 → 3 → 4 → 5(보스)` 주선, `2 → 6 → 7 → 3` 우회선, `3 → a` 막다른 보상방으로 구성한다. 진입 방은 마을과 2번 방으로 이어지는 포탈 둘만 둔다.

## 몬스터 정본

| 지역 | 일반 몬스터 | 보스 | 공식 MSW 팩 |
|---|---|---|---|

| 미나르숲 | 하프, 블러드 하프, 블루 와이번, 다크 와이번 | 마뇽 | `mob/8140001.img`, `8140002`, `8150301`, `8150302`, `2600022` |
| 시간의 신전 | 추억의 사제, 추억의 신관, 추억의 수호병, 추억의 수호대장 | 도도 | `mob/8200001.img`~`8200004.img`, `8220004` |
| 지구방위본부 | 마티안, 플라티안, 메카티안, 원로 그레이 | 제노 | `mob/4230119.img`~`4230121.img`, `4240000`, `6220001` |

지역 소속은 MapleStory Wiki의 [무릉](https://maplestorywiki.net/w/Mu_Lung), [미나르숲](https://maplestorywiki.net/w/Minar_Forest), [시간의 신전](https://maplestorywiki.net/w/Temple_of_Time), [지구방위본부](https://maplestorywiki.net/w/Omega_Sector) 문서와 공식 MSW Resource Storage 몬스터 팩을 교차 확인했다. 지구방위본부의 원로 그레이·제노는 현재 개편판이 아니라 프로젝트가 채택한 구판 몬스터군에 속한다.

## 포획 스킬

| 지역 | 액티브 3종 | 패시브 2종 |
|---|---|---|
| 무릉도원 | 목인 회전타, 천도 투척, 태륜의 쌍권풍 | 짚단 균형감각, 청화 비늘 |
| 미나르숲 | 핏빛 깃울림, 빙룡 숨결, 마뇽의 용화염 | 하늘 둥지의 날갯결, 검은 비늘의 근력 |
| 시간의 신전 | 추억의 기도파, 시간 수호진, 기억 포식 | 추억의 묵상, 수호병의 기억갑주 |
| 지구방위본부 | 마티안 광선탄, 기계화 레이저, 제노의 중력장 | 외계 장갑 조종, 원로의 정신연산 |

연출은 임의 소재를 섞지 않고 각 몬스터 공식 팩의 공격·투사체·피격·경고 애니메이션 RUID만 조합했다. 보스 스킬 네 종은 다음 지역 보상방을 여는 열쇠다.

## 장비와 UI 수용량

- 몬스터마다 공식 MSW 아바타 카탈로그 장비 1종을 연결했다. 재료 아이템은 추가하지 않았다.
- 보스 장비는 기존 런타임의 보스 전용 확정 드랍 경로를 사용한다.
- 전체 포획 대상 91종에 맞춰 스킬 창을 91칸으로 확장했다.
- 방어구가 44종으로 36칸을 넘으므로 가방을 6×8, 48칸으로 확장했다. 창 전체 높이는 유지하고 슬롯과 아이콘만 촘촘하게 조정했다.

## 타일

공식 검색에서 나온 후보는 큰 오브젝트·횡스크롤 발판이어서 100×100 RectTile 반복에 부적합했다. `msw-painter` chunky pixel 규격으로 지역별 4종, 총 16종을 제작해 계정 Resource Storage에 등록했다.

| 지역 | 통과 가능 3종 | 통과 불가 1종 |
|---|---|---|
| 무릉도원 | 복숭아 흙, 도장석, 대나무 길 | 운무 절벽 |
| 미나르숲 | 고대 이끼, 낙엽 바닥, 용비늘 길 | 가시 심연 |
| 시간의 신전 | 기억 대리석, 풍화 석판, 시간 문양 | 시간의 공허 |
| 지구방위본부 | 기지 강철, 경고판, 외계 회로 | 에너지 홈 |

각 스프라이트는 100×100, `Point`, `Repeat`, 중앙 피벗으로 등록했다. 32개 맵은 모두 RectTile `TileMapMode=1`, 28×16=448칸이다.

## 검증

- `node docs/tools/verify-area15-area18.cjs`: 4지역·32방·20모델·20스킬·20장비, 448타일, 왕복 연결, 포탈, 위험 타일 충돌 통과
- `node docs/tools/verify-content-coverage.cjs`: 91몬스터·91스킬·94아이템·20보스, 누락 0, 스킬 91칸·가방 48칸 바인딩 통과
- `node docs/tools/verify-region-audit-corrections-t66.cjs`: T66 배치·지형 회귀 검사 통과
- Maker Refresh 후 `map151`~`map187`과 각 지역 `a` 보상방, 총 32개 ID를 편집 모드에서 전부 순회해 등록 상태 `ok`를 확인했다. Maker 저장은 호출하지 않았다.
- Play에서 `map151`, `map161`, `map171`, `map181`의 일반 몬스터 본체·지역 타일·미니맵을 확인했다. 스폰 로그는 수련용 짚인형, 하프, 추억의 사제, 마티안을 각 방 설정 레벨과 정원대로 기록했다.
- `map155`, `map165`, `map175`, `map185`에서 태륜·마뇽·도도·제노 본체와 보스 HUD를 확인했다. HP는 각각 52,400 / 55,820 / 59,240 / 62,660으로 기본 HP의 ×10이고, 제한시간은 입장마다 5:00으로 초기화됐다.
- 동일 보스방을 나갔다 다시 들어오면 새 본체가 최대 HP로 생성됐다. 제노 처치에서는 `i_zeno_galaxy_helmet`이 기본 0.020임에도 `[보스 전용 확정]`으로 확률 1.000 드랍했다.
- 새 `eyeaccessory` 장비 분류를 `GameDataVerify`와 `PlayerInventory.GetAvatarCategory`에 연결했고, 재실행 결과 일반 로그 오류 0건이다. 빌드 콘솔에는 기존 `mano`·`bowmaster` 경고 2건만 남았다.
- 확정 드랍 검증 중 변한 테스트 프로필은 시작 로그의 `Lv122 / EXP 942,962 / r_13a / 최고Lv122 / 보스 12`로 원복하고 저장했다. T67 포획 천장·보스 기록·신규 장비도 제거했다.
- `SectorConfig`는 Maker 관리 파일이라 직접 수정하지 않았다. 정적 검증기의 `sectorMissing` 안내와 무관하게 실제 32맵 ID 전환은 모두 성공했다.
