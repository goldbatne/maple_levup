# T65 지역 확장 — Lv101~140

> 작성: 2026-09-09 · 실행 정본은 GameData CSV, `.model`, `.map`, `.tileset`이다.

## 범위

| 지역 | 레벨 | 해금 | 일반 몬스터 | 보스 |
|---|---:|---:|---|---|
| `area_11` 루더스 호수 | 101~110 | Lv100 | 라츠, 북치는 토끼, 블록퍼스, 킹 블록퍼스 | 롬바드 |
| `area_12` 루디브리엄 | 111~120 | Lv110 | 브라운테니, 장난감 목마, 마스터 로보, 크로노스 | 타이머 |
| `area_13` 니할 사막 | 121~130 | Lv120 | 흰 모래토끼, 목도리 프릴드, 미요캐츠, 모래난쟁이 | 데우 |
| `area_14` 마가티아 | 131~140 | Lv130 | 큐브슬라임, 미스릴 뮤테, 호문, 로이드 | 키메라 |

각 지역은 기존 규격과 같은 8방이다. 진입방에서 본선이 동쪽으로 진행되고 두 번째 방의 남쪽 분기가 우회로를 거쳐 보스 직전 방으로 합류한다. 북쪽 막다른 방은 직전 지역 보스 포획 스킬을 요구하는 보상방이다. 보스 직전 스탯 게이트는 차례로 515, 565, 615, 665다.

## 몬스터 교차 검증

- 원작 지역 소속은 MapleStory Wiki의 [Ludus Lake](https://maplestorywiki.net/w/Ludus_Lake), [Monster Collection](https://maplestorywiki.net/w/Monster_Collection), [Nihal Desert](https://maplestorywiki.net/w/Nihal_Desert), [Ariant](https://maplestorywiki.net/w/Ariant), [Magatia](https://maplestorywiki.net/w/Magatia) 문서로 확인했다.
- 보스 후보는 같은 지역 문서와 Monster Collection의 원작 등장 지역·보스 분류를 기준으로 정했다.
- MSW Resource Storage에서 20종 모두 공식 `mob/*.img` 리소스 팩과 이동·피격·사망 동작을 확인했고, 보스 4종은 공격 또는 스킬 클립도 확인했다.
- 원작 레벨은 소속 교차 검증에만 사용했다. 실제 Lv101~140과 HP·DEF·ATK·EXP는 프로젝트의 연속 성장 공식으로 다시 계산했다.

## 콘텐츠

- 맵 32개: `map111`~`map117`, `map11a`부터 `map141`~`map147`, `map14a`까지
- 몬스터 모델 20종, 포획 스킬 20종, 장비 20종
- 지역별 포획 스킬은 액티브 3종·패시브 2종이다.
- 장비는 공식 MSW 아바타 아이템 이름과 아이콘을 사용한다. 재료 아이템은 추가하지 않았다.
- 보스방은 공통 규격 HP ×10, DEF ×1, ATK ×1.5, 제한시간 300초, 장비 확정 드랍을 그대로 사용한다.
- 전용 타일은 지역별 4종이다. 신규 `.tileset`은 Maker가 직접 등록하지 못하므로 기존 Lv61~100 타일셋의 5~8번 슬롯으로 확장했다. 이전 지역은 1~4번, 신규 지역은 5~8번만 사용한다. 루더스 호수의 탑 낙하부, 루디브리엄의 기어 구덩이, 니할 사막의 유사, 마가티아의 약품 수로는 통과 불가 타일이다.
- 스킬 장착 격자는 누적 포획 스킬 70종을 모두 표시하도록 70칸으로 늘렸다. 아이템 가방은 최대 분류인 방어구 35종으로 기존 36칸 안에 들어간다.

## 정적 검증

- `verify-area11-area14.cjs`: 32맵 모두 448타일, 왕복 연결, 포탈, 스폰, 모델, 스탯 공식, 위험 타일 충돌 통과
- `verify-content-coverage.cjs`: 누적 70몬스터·70포획 스킬·73아이템·16보스와 UI 수용량 검사
- `SectorConfig`에는 오프라인 생성 맵이 기록되지 않았지만 Maker가 신규 32맵을 모두 찾아 Play 전환했다. 따라서 등록 여부는 `SectorConfig` 문자열보다 실제 `move_map`·Play 결과를 정본으로 판정했다.

## Maker 검증

- 신규 32맵 모두 목표 맵 전환 성공. `map111`은 라츠 4마리, 각 지역 일반방은 해당 몬스터 스폰·리필 로그를 확인했다.
- 롬바드 HP 38,720, 타이머 42,140, 데우 45,560, 키메라 48,980. 네 보스 모두 300초로 시작했다.
- 키메라의 `융합체의 산성 포격` 발동과 실제 피해를 확인했다.
- 키메라 처치 후 장비 확정 드랍 확률 1.000, 재입장 HP 48,980/48,980·남은 시간 약 299초를 확인했다.
- 첫 Refresh에서 폐기한 신규 tileset 4개의 과거 Build 오류가 지워지지 않는 현상이 남았다. 현재 파일과 맵에는 해당 ID가 없고 기존 tileset 확장 방식으로 32맵 Play가 정상 동작한다.
