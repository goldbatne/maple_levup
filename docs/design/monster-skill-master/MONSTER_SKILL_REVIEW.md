# Lv1~200 포획 몬스터 스킬 이름 정합성 검토

- 기준 스냅샷: 2026-09-10 현재 작업 트리의 MonsterTable.csv, SkillTable.csv, AreaTable.csv, RoomTable.csv, 몬스터 model 파일
- 범위: MonsterTable.drop_skill_id가 비어 있지 않은 Lv1~200 몬스터 101종
- 변경 원칙: 게임 데이터·스킬명·이미지·RUID는 수정하지 않았으며 이 보고서와 CSV만 생성했다.
- 주의: **적합은 원작에 동일한 공식 스킬이 존재한다는 뜻이 아니다.** 원작 몬스터/지역 정체성과 현재 창작 이름이 자연스럽게 연결되는지를 판정했다.

## 판정 방법과 근거 수준

- [P] 현재 프로젝트 1차 자료: 네 CSV와 실제 몬스터 모델의 SpriteRUID.
- [A] 프로젝트 감사 기록: docs/archive/reports/몬스터_매칭_감사_T52.md 및 docs/인수인계_현재상태.md의 공식 MSW 리소스/지역 교차검증 기록. 넥슨 원문과는 구분했다.
- [N] 넥슨 공식 자료. 확인 가능한 지역·퀘스트 범위에만 사용했다.
- [W] 커뮤니티 위키·가이드 보조 자료. 오래된 퀘스트/몬스터 서사 확인에만 사용하고 공식 근거와 구분했다.
- 공식 고유 능력을 찾지 못한 경우 만들어내지 않았다. 정본 몬스터명·종족명·확인된 배치 지역과 이름이 직접 이어지는 경우만 사용자의 자연스러운 연결 기준으로 적합 처리했다.
