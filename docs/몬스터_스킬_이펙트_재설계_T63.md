# T63 몬스터 스킬 이펙트 재설계

## 목적

Lv1~60 및 노틸러스까지의 몬스터 스킬에서 생성형 이미지 특유의 광택·복잡한 장식·일관되지 않은 실루엣을 제거한다. 전직 스킬을 통째로 복제하지 않고, 각 몬스터의 원작 소재와 스킬 이름이 즉시 읽히는 짧은 조합형 연출로 통일한다.

## 현행 제작 규격

- 생성형 커스텀 스프라이트를 사용하지 않는다.
- 아이템·전리품·몬스터 본체 스프라이트를 시전 이펙트로 사용하지 않는다. 해당 소재는 스킬 아이콘에서만 쓴다.
- 시전 연출은 몬스터의 행동과 이야기를 해석한 MSW `animationclip` 조합으로 만든다.
- 타격 먼지·물보라·불꽃·지면 충격 등은 MSW Resource Storage의 짧은 animationclip으로 보조한다.
- 한 스킬은 여러 RUID 레이어의 지연, 위치, 이동, 크기, 수명으로 구성한다.
- 스킬 이름과 몬스터 설정에 없는 무기·속성·버프는 추가하지 않는다.
- 패시브 7종은 공격 이펙트를 재생하지 않는다.

## 주요 교정

- `붉은 껍질 돌진`: T60에서 만든 전용 스킬 아이콘 `4292e76e…`를 복원했다. 시전 중에는 껍질 아이템을 띄우지 않고 붉은 가속 잔상·흙먼지·충돌만 재생한다.
- `도끼 휘두르기`: 검기나 아이템 도끼를 띄우지 않는다. 몸을 비트는 박자에 맞춰 흙먼지와 전방 충격만 남겨, 장비 아이템이 튀어나오는 오독을 막았다.
- `고목의 생기탄`: 실제 사용 시 플레이어 몸에 먼저 생기던 초록 오라 두 겹을 제거했다. 별도 생기탄 투사체·시전음·착탄 판정만 유지한다.
- `다크 엑스텀프`: 무기 투척이나 버프가 아니라 보라색 지면 뿌리 가시 두 줄로 표현한다.
- 일반 버섯: 원작 포자 세 덩이가 공중에서 부채꼴로 흩어진다.
- 머쉬맘: 지면 충격과 넓은 충격파 뒤에 큰 머쉬맘 포자가 한 번 터진다. 일반 버섯의 포자 살포와 실루엣·방향·박자를 분리했다.
- 스켈레톤 지휘관: 지면 파쇄와 잔류 충격으로 지휘관의 묵직한 공격을 표현하며, 뼈 재료 아이템은 띄우지 않는다.
- 옥토퍼스: 물보라 뒤 검보라 먹물 덩이가 남는다.
- 리본 돼지·불가사리: 재료 아이콘 대신 돌진 잔상과 물보라·둥근 파도로 각각의 움직임을 표현한다.

## 안전장치

`docs/tools/verify-content-coverage.cjs`가 다음을 검사한다.

- 현재 지역 액티브 스킬 23종의 정확한 레이어 수
- 액티브 스킬의 시각 레이어 누락
- 폐기한 생성형 커스텀 RUID의 재유입
- 재료 아이템 RUID 및 `sprite` 레이어의 재유입
- Maker에서 비가용이거나 의미가 어긋나 탈락한 후보 RUID의 재유입
- 패시브 스킬에 공격 이펙트가 붙는 문제

## 검증 결과

- 정적 콘텐츠 검사: 통과
- Maker 전체 액티브 스킬 스윕: `[T63 FINAL2] COMPLETE 23/23`
- 런타임 오류: 0
- 런타임 경고: 0
- 빌드 오류: 0
- 기존 경고 2건은 Mano의 `MovementComponent.InputSpeed`, Bowmaster의 `MonsterAttack.AvatarAttackPlayRate`로 이번 이펙트 변경과 무관하다.
- 화면 확인 완료: 붉은 껍질, 일반 버섯, 머쉬맘, 도끼 나무, 다크 엑스텀프, 불가사리, 스켈레톤 지휘관, 옥토퍼스.

## 리소스 운용 메모

검색 결과의 이름·썸네일이 적절해 보여도 실제 Maker에서는 검기·클로버·종처럼 전혀 다른 형상으로 재생되거나 RUID가 비가용일 수 있다. 반드시 Play 모드에서 후보를 분리 재생해 판정한다. 이번에는 머쉬맘의 초록 재료형 후보, 도끼로 검색됐지만 검기/클로버로 보인 후보, 비가용 RUID 2개를 탈락 목록에 고정했다.

RectTile에서는 Y가 화면 높이가 아니라 이동 평면이다. 공통 `skill_effect_height`를 0으로 두어 시전자 중심에 맞추고, 스킬별 앞·뒤·좌·우 배치는 각 레이어 오프셋으로만 조절한다. 이번 변경에서는 저장소에 새 이미지를 생성하거나 업로드하지 않았다.
