# 사선 타일 전수 점검 및 교체 (2026-10-04)

## 범위와 판단

프로젝트의 `.map` 162개와 실제 연결된 타일셋을 읽기 전용으로 대조했다. 사용자 화면의 긴 사선은 `RectTileData_Nautilus.tileset`의 모래 타일 `Nautilus_sand_2`(index 1)와 물 타일 `Nautilus_water`(index 3)에서 왔다. 이 타일셋을 사용하는 맵은 18개이며, 그중 실제 사선 타일을 칠한 맵은 17개다. `map05a`는 같은 타일셋을 쓰지만 두 타일 모두 0개이므로 외형 변경 대상이 아니다.

Room/Area 데이터 기준 의도는 두 묶음이다. Area 00은 메이플 아일랜드·리스항구의 초반 해안/선착장 구역, Area 05는 노틸러스의 해변/바다/갑판 구역이다. 따라서 지형이나 맵 개념을 다른 지역으로 바꾸지 않고, 물은 잔잔한 청록빛 물결, 모래는 작은 입자가 있는 황갈색 바닥으로 보이도록 같은 리소스의 그림만 교체했다.

## 실제 변경

- `docs/art/tiles/nautilus/01_sand_2.png`: 규칙적인 사선 음영을 비방향성 모래 입자로 교체.
- `docs/art/tiles/nautilus/03_water.png`: 길게 반복되는 흰 사선을 작은 불규칙 물결로 교체.
- 원본 백업: 같은 폴더의 `01_sand_2_original_diagonal.png`, `03_water_original_diagonal.png`.
- Maker 계정 리소스도 **기존 RUID 그대로** 바이너리 갱신: 모래 `32093780fa3a49d493ca192b2da5131d` (version `6ac1f816cd57f8c8ffdb40e1`), 물 `ad7134c1000e4d4ab4087ea949a60531` (version `6ac1f83dcd57f8c8ffdb411e`). 계정 리소스 메타데이터 재조회는 두 건 모두 성공했다.
- `.map` 타일 배열, 타일 index, 통과/충돌 지형, 몬스터/포털 배치는 수정하지 않았다.

## 검증 범위

- `map001_before.png` / `map001_after.png`: 섬 초반 해안의 물·모래 경계가 유지되며 긴 사선이 사라짐.
- `map054_before.png` / `map054_after.png`: 노틸러스 바다와 갑판의 위치는 같고 물 사선만 사라짐.
- `map007_after.png`, `map004_after.png`, `map051_after.png`: 대표 맵의 오프라인 타일 반복 미리보기 생성.
- `git status -- map ui Global`: 해당 맵·UI·Global 파일 변경 없음.
- Maker 연결은 확인했으나 현재 편집 맵은 `maptown`이다. 다른 맵으로 전환할 때 미저장 편집 상태에 영향을 줄 수 있고, 선행 작업으로 `RootDesk/MyDesk`가 `Mislocated/MyDesk`로 이동한 워크스페이스 문제가 남아 있어 이번에는 Refresh/Play를 하지 않았다. 따라서 **Maker 화면·런타임 검증은 NOT_RUN**이며, 오프라인 이미지 검토와 계정 리소스 조회까지만 완료다.

이 보고서는 타일 모양 수정 범위를 명확히 기록한다. Maker 재진입 시 `map001`과 `map054`를 열어 실제 렌더링과 캐시 갱신을 확인해야 최종 시각 PASS로 올릴 수 있다.
