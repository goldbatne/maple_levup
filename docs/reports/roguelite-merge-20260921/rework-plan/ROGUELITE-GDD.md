# Area Breaker — 로그라이트 개편 GDD

> HISTORICAL / 병합 당시 고정 슬롯 개편안. 후속 Mega Area 랜덤 재고 사양이 사용 체계를 대체했다. 현행 기준: [CURRENT_GAME_STATE.md](../../../CURRENT_GAME_STATE.md). 이 문서를 최신 구현 지시로 적용하지 않는다.

## 한 줄 정의

매번 새롭게 연결되는 Area를 탐험하며 몬스터 능력을 확정 획득하고, 원하는 능력 다섯 개를 고정 슬롯에 구성해 목표를 해결하는 1~4인 실시간 로그라이트.

## 핵심 루프

Area 선택 → 참가자 확정 → Seed 기반 Room 그래프 생성/검증 → 탐색/전투 → 능력 획득/교체 → 선택 위험 구역 → 지정 강적 또는 최종 지점 → 결과 기록 → 공통 시작 상태로 복귀.

## 전투

- 기본 공격: 최근접 유효 적 1체, 항상 사용 가능.
- Run 시작: 공통 HP/공격/방어와 빈 능력 슬롯 5칸.
- 능력 획득: 연결된 액티브/방어 능력을 가진 몬스터 처치 시 자격 참가자에게 확정 제공.
- 빈 슬롯: 첫 빈 슬롯에 자동 등록.
- 가득 찬 슬롯: 교체 슬롯 선택 또는 포기. 자동 덮어쓰기 없음.
- 장착 능력: 사용 후 유지, SkillTable 쿨다운 후 재사용. 동일 SkillID 중복 장착 불가.
- 쿨다운 0/누락: `run_skill_cooldown_fallback` 사용. 슬롯 이동·재획득·맵 이동·부활로 초기화하지 않음.
- 스킬 고유 효과·계수·범위·타격 횟수·VFX는 감사 기준본과 동일하게 유지.

## 절차 생성

각 Area의 기존 RoomTable 레코드와 맵을 사람이 설계한 템플릿으로 사용한다. 생성기는 시작방과 최종방 사이의 주 경로를 만들고, 방향이 호환되는 남은 방을 선택 위험 가지길로 연결한다. 재시도 상한 뒤에는 원래 Area 연결을 안전 배치로 사용한다.

동일 `Seed + generator_version + Area 데이터`는 같은 초기 그래프를 만든다. 전투 난수는 생성 난수와 분리한다.

필수 진행은 기본 이동과 기본 공격만으로 가능해야 한다. 현재 프로토타입 목표는 최종 공간의 지정 강적 1체 처치다.

## 솔로와 협동

- 1~4인, 시작 참가자 고정, 중도 난입 차단.
- 서버 InstanceRoom이 맵 집합과 참가자를 확정한다.
- HP 배율: `1 + 0.25 × (시작 인원 - 1)`; 공격력과 개체 수에는 같은 배율을 중복 적용하지 않는다.
- 처치 위치 반경 안의 참가자에게 개인별 능력 획득 기회를 지급한다. 막타 독점이 아니다.
- 일부 사망자는 관전 상태가 되고 다음 안전 전환에서 재합류한다. 전원 사망/이탈 시 실패.
- 재접속 유예 기본 90초. 쿨다운과 장착 슬롯은 부활/전환으로 초기화하지 않는다.

## 영구 기록과 Run 상태

영구 기록은 별도 `RoguelitePermanent` namespace의 발견 몬스터, 발견 능력, Area 클리어, 선택 조우, 설정뿐이다. 레벨·장비·테이밍·별 성장은 신규 전투력에 합산하지 않는다.

Run 종료 시 장착 슬롯, 쿨다운, HP, 후보, 목표/생성 진행을 정리한다. 기존 RPG/M2 저장 필드는 그대로 보존한다.

## UI

- 전투 HUD: HP, 고정 5슬롯, 키, 쿨다운, Area/Seed/목표.
- 획득: 몬스터·능력 이름, 교체할 슬롯 또는 포기.
- 컬렉션: 영구 발견 기록만 보여주며 시작 능력이나 전투력을 제공하지 않는다.
- 숨김: EXP/레벨/직접 스탯, 장비 성장, 전직/환생, Trait, 테이밍/동행, 랜덤 공급 대기.

## 의도적으로 제외

랜덤 공급, 슬롯 소비, 확률 포획, 중복 강화, 영구 전투력 파밍, AI 동료, PvP, 상점/덱/카드, 전체 맵 일괄 축소는 포함하지 않는다.
