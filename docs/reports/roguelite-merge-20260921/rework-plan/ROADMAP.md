# 구현 로드맵 및 상태

## R1 기준본 분리 — 완료

- 스킬 감사 baseline_id와 해시 기록
- 별도 작업본 구성
- 원본 프로젝트 비수정 확인

## R2 고정 5슬롯 전투 — 정적 구현 완료 / 런타임 미검증

- 빈 슬롯 자동 등록, 5칸 교체/포기, 중복 금지
- 사용 후 슬롯 유지
- SkillID별 쿨다운 및 명시적 대체값
- 랜덤 공급/소비 경로 신규 모드 차단

## R3 절차 생성 Area — 정적 프로토타입 완료 / 런타임 미검증

- Area Room 템플릿 목록
- Seed 기반 주 경로와 가지길
- 방향 호환 검사, 재시도 상한, 원본 그래프 fallback
- Run 한정 조우 및 최종 지정 강적 목표

## R4 솔로 Run — 정적 구현 완료 / 런타임 미검증

- InstanceRoom 시작
- 성공/전원 사망 실패
- 영구 발견/클리어 기록과 Run 상태 정리

## R5 1~4인 협동 — 서버 구조·최소 준비 흐름 구현 / 실기 검증 미완료

- Area 첫 클릭 준비/같은 Area 재클릭 시작, 같은 대기 맵·준비 상태 서버 검증
- 시작 참가자 고정, 중도 난입 차단, HP 배율
- 반경 기반 개인 획득
- 생존자 포탈 집결·서버 단일 전환, 사망 관전/전환 재합류/재접속 유예
- 남은 일: 참가자 명단/상태 전용 UI, 실제 2~4인 동기화 검증

## R6 지형/스킬 호환 — 미완료

- 투사체 벽 충돌, 돌진 지형 이탈, 벽 너머 범위 판정은 감사 기준 기능을 유지했다.
- Maker에서 의도와 오류를 구분하기 전 일괄 수정하지 않는다.

## R7 콘텐츠 확대 — 보류

현재 20 Area/160 Room 자산은 템플릿 후보이나, Maker 검증을 통과한 Area만 메뉴에 노출해야 한다.
