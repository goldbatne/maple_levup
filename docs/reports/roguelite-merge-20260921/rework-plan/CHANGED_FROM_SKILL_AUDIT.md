# 스킬 감사 기준본 대비 변경

스킬 자체의 이름, 몬스터 연결, 계수, 사거리, 범위, 타격 횟수, 지속시간, VFX는 수정하지 않았다.

| 영역 | 기준본 | 개편본 |
|---|---|---|
| 획득 | 확률 테이밍/영구 보유 | Run 안에서 처치 시 자격 참가자에게 확정 후보 |
| 슬롯 | 5초 랜덤 공급, 일회성 재고 | 플레이어가 고르는 고정 5슬롯 |
| 사용 후 | 슬롯 소비 | 슬롯 유지 |
| 중복 | 같은 SkillID 재고 중복 가능 | 같은 SkillID 중복 장착 금지 |
| 재사용 | 신규 랜덤 모드에서 쿨다운 무시 | SkillTable 쿨다운, 0/누락은 명시적 공통값 |
| 성장 | 레벨/장비/수집 단계 영향 | 신규 모드 공통 기본 능력치만 사용 |
| 맵 | 고정 Room 연결 | 같은 Area의 기존 Room을 Seed로 재연결 |
| 보상 | 막타 중심 경로 포함 | 같은 방 근접 참여자에게 독립 제공 |

환경 충돌 판정은 바꾸지 않았다. 새 연결에서 투사체·돌진·범위 공격이 벽과 어떻게 상호작용하는지는 Maker 검증 대상이다.
