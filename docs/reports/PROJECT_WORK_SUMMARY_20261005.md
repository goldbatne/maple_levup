# 프로젝트 작업 내역 통합 보고서

기준일: 2026년 10월 5일 / 프로젝트: `D:/maplestory_levup`

## 1. 현재 상태 요약

현재 프로젝트는 **몬스터를 탐험으로 수집하고, 편성한 몬스터를 성장시키며, 솔로 또는 파티로 랜덤 던전을 도전하는 액션 RPG** 형태로 정리되어 있다.

10층 도전, 두 전투 모드, 메인 동행과 지원 편성, 영구 성장, 성장 보조 상점, 몬스터 스킬 효과음 연결까지 구현 기록이 있다. 가장 최근에는 각 맵의 원작 지역 BGM을 추가했다.

이 보고서는 기존 작업 기록과 현재 파일을 통합한 문서다. **이번 문서 작성 중 게임을 다시 실행하거나 전 항목을 재검증하지 않았다.** 따라서 ‘구현됨’, ‘기존 실행 기록 있음’, ‘사용자 확인’, ‘미검증’을 구분한다. 게임 전체가 무결하거나 출시 검증이 모두 끝났다는 의미는 아니다.

### 판정 기준

| 표기 | 의미 |
|---|---|
| 구현 확인 | 현재 코드·데이터 또는 최신 커밋 기록에 해당 처리가 있음 |
| 기존 Maker 검증 | 이전 보고서에 실제 실행 근거가 있음. 당시 검사 범위에만 적용 |
| 사용자 확인 | 사용자가 직접 확인했다고 알려준 사항. 이번 자동 재검증 아님 |
| 검증 대기 | 현재 상태로 실제 실행·청취·운영 검증이 남음 |

## 2. 콘텐츠 규모

이번 정리에서 현재 CSV와 BGM 자료를 읽어 확인한 수량이다.

| 항목 | 수량 | 해석 |
|---|---:|---|
| MonsterTable 정의 | 103 | 수집 대상 101종 + 히어로·보우마스터 별도 정의 2종 |
| SkillTable 전체 정의 | 112 | 레거시·패시브·전직 관련 정의도 포함. 실제 액티브 수와 다름 |
| 몬스터 액티브/방어 사운드 대상 | 66 SkillID | 기존 사운드 전수조사·매핑 보고서 기준 |
| 연결된 비활성 패시브 | 35 | 데이터 존재가 Run 발동 가능하다는 뜻은 아님 |
| 지역 | 20 | 5개 Mega Area 묶음으로 사용 |
| RoomTable 등록 맵 | 159 | 기존 방 정의 |
| 전체 .map 파일 | 162 | 위 159개 + 기존 프로토타입 3개 |
| ItemTable 정의 | 104 | 레거시 정의 포함. 전부 현재 Run 드롭이라는 뜻은 아님 |
| VARCO 최종 WAV / OGG | 67 / 67 | 66개 기본 스킬음 + 추억의 신관 강화 타격음 1개 |
| 지역 BGM | 37곡 | 기존 맵 162개에 연결 |

히어로·보우마스터는 몬스터 스킬용 VARCO 제작 대상에서 제외했다. SkillTable의 전체 `sfx_ruid` 채워진 행은 75개지만, 이를 신규 VARCO 음원 75개로 세지 않는다. 기존·별도 정의와 이번 66개 연결을 구분해야 한다.

## 3. 던전 진행과 난이도

### 진행 구조

- 솔로 또는 최대 4인 파티로 Run 시작.
- NORMAL / MONSTER_SKILL 두 모드 유지.
- Seed 기반 방 구성, 혼합 몬스터 조우, 가지길, 탐험 상자, 보스 및 결과 정산.
- 5개 Mega Area를 두 층씩 공유하여 **총 10층**으로 확장.
- 해금한 층은 클리어 후에도 다시 도전할 수 있음.
- 다음 층은 앞선 층의 최고 랭크가 S 이상일 때 해금.
- 전체 던전 제한 20분. S는 15분 이내, A는 18분 이내, 그 이후 제한 시간 안의 클리어는 B.

### 적 능력치와 보상

기본 적 HP·공격·방어에는 2배 난이도 배율을 적용한다. 층별 배율은 `1 + (층 - 1) × 0.25`이며, 두 배율을 곱한다. 보스 HP 배율과 파티 인원에 따른 HP 보정은 별도다.

| 층 | 층 배율 | 기본 난이도 포함 배율 | 클리어 성장 점수 | 클리어 성장 코어 | 환경 기믹 고정 피해 |
|---:|---:|---:|---:|---:|---:|
| 1 | 1.00 | 2.00 | 5 | 0 | 없음 |
| 2 | 1.25 | 2.50 | 10 | 0 | 없음 |
| 3 | 1.50 | 3.00 | 15 | 2 | 없음 |
| 4 | 1.75 | 3.50 | 20 | 2 | 없음 |
| 5 | 2.00 | 4.00 | 25 | 3 | 10 |
| 6 | 2.25 | 4.50 | 30 | 3 | 20 |
| 7 | 2.50 | 5.00 | 35 | 4 | 40 |
| 8 | 2.75 | 5.50 | 40 | 4 | 40 |
| 9 | 3.00 | 6.00 | 45 | 5 | 40 |
| 10 | 3.25 | 6.50 | 50 | 5 | 40 |

위 표는 현재 설정과 계산식을 정리한 것이며, 10개 층의 자연 전투 체감 검증 결과가 아니다.

MONSTER_SKILL 모드는 **사용자별·층별 하루 3회** 성장 점수·코어 확정 클리어 보상을 제공한다. 횟수를 다 써도 도전과 클리어는 가능하지만 해당 확정 보상은 지급하지 않는 경로가 있다. 남은 보상 횟수 표시를 반영한 작업 기록이 있다.

### 5층부터 환경 기믹

- 몬스터 스킬을 원본으로 한 환경 공격.
- 발동 3초 전 타원형 위험 영역 표시.
- 5층 10, 6층 20, 7~10층 40의 최종 고정 피해.
- NORMAL / MONSTER_SKILL 양쪽에 적용하는 작업 범위.
- 기존 스킬 발동 방향과 기믹 영역 중심의 VFX 위치를 보정한 기록.
- 기믹은 회피를 요구하는 고정 피해이며 일반 공격의 방어 계산과 구분한다.

## 4. 몬스터 수집·성장·동행

### 수집과 성장

- 몬스터 해금은 탐험으로 획득하는 방향으로 정리.
- 기존 ‘몬스터 선택권’을 **몬스터 성장권**으로 변경. 미보유 몬스터 해금 수단이 아니라 보유 몬스터 성장 보조로 사용.
- 몬스터 레벨 상한 20, 별도 강화 상한 +20.
- 성장 점수로 강화, 성장 코어로 레벨업하는 구조.
- 처치 성장 점수 추첨: 일반 적 5%, 보스 12%.
- 성장 코어는 3층부터 추첨: 일반 적 1%, 보스 3%.
- 플레이어 능력치에 편성 3마리의 유효 HP·공격·방어 합계 50%를 전달하는 설정.
- 지원 몬스터는 메인 동행에 HP·공격·방어를 각각 20% 전달하는 기존 구조 유지.

‘하루 몬스터 3마리 해금’과 초기 선택권 정책은 과거 설계다. 현재 성장권의 기능과 혼용하지 않는다.

### 동행 목숨과 회복 상자

- 메인 동행은 Run 시작 시 목숨 3개.
- 사망 시 1개 소모. 남아 있으면 2초 후 재소환.
- 방 이동으로 목숨을 복구하지 않으며 살아 있는 동행의 남은 HP도 유지.
- 목숨 0이면 다음 방에서도 소환하지 않음.
- 회복 상자는 플레이어와 살아 있는 메인 동행을 회복.
- 목숨이 부족하면 20% 확률로 1개 회복, 최대 3개.
- 0→1 회복 시 다시 소환 가능.
- 상태는 Run 내 사용자별로 보관하며 목숨을 계정 영구 재화로 저장하지 않음.

**기존 Maker 근거:** 자연 전투 사망 3→2, 방 이동 HP 유지, 회복 상자 양쪽 회복, 같은 상자의 중복 효과 방지, 목숨 0 상태의 방 이동을 확인한 기록이 있다. 목숨 회복 분기는 테스트 중 확률을 100%로 올려 검사한 뒤 20%로 복원했다. 실제 20% 확률의 통계적 분포까지 검증한 것은 아니다.

## 5. 스킬 획득·전투·드롭 상호작용

- 적격 능력의 첫 획득 보장 및 이후 획득 확률 처리.
- 스킬 자동 지급과 파티 대상 분배, 중복 보유 시 다른 적격 팀원에게 넘기는 방향 반영.
- 솔로에서 이미 보유한 능력을 다시 획득할 수 없는 안내 처리.
- 보유 능력 풀에서 빈 5슬롯 중 한 곳에 5초 주기로 랜덤 공급.
- 실제 사용 성공 시 슬롯 재고 소비.
- 보스 스킬 사용 경로를 두 모드에 반영한 작업 기록.
- 방어 수치의 피해 감소 및 동행·플레이어 능력 전달 처리.
- 드롭 아이템·상자에 E와 클릭/터치 상호작용 경로 추가.
- 스킬/VFX의 시전자 방향 및 타원 기믹 중심 정렬 보정.

스킬 자동 획득의 최종 체감 검증은 사용자가 직접 확인하기로 한 범위가 있었다. 코드 경로가 있다는 사실을 모든 파티 조합·모바일 터치·모든 스킬의 자연 전투 PASS로 확대하지 않는다.

## 6. 마을·채널·파티

- 마을 채널과 던전 파티 인스턴스를 분리하는 구조.
- 파티 이름으로 만들고 공개 목록에서 선택 참가하는 UI.
- 출시 월드에서 공식 WorldInstance 목록을 사용해 채널 인원과 정원을 표시.
- SharedMemory 기반으로 다른 채널의 공개 파티 목록을 공유하는 경로.
- 다른 채널 파티 참가 시 대상 채널을 확인하고 이동·참가하는 경로.
- 인원 0인 채널을 공개 목록에서 제외.
- 정원은 실제 플랫폼 `MaxUserCount`를 사용. 코드의 표기만으로 출시 정원이 바뀌었다고 보지 않음.

초기의 ‘20개 마을 맵을 고정 생성’ 구상과 현재 공식 월드 인스턴스 기반 채널 구현은 구분해야 한다. 빈 채널을 목록에서 빼는 것과 플랫폼 인스턴스를 직접 종료하는 것도 같은 의미가 아니다.

사용자는 멀티와 실제 유료 결제를 직접 확인했다고 알렸다. 이는 **사용자 확인 기록**으로 남기며, 이번 문서 작성에서 출시 월드의 다중 채널·대규모 동시 접속을 다시 시험한 것은 아니다. 현재 출시 정원·채널 공개 상태도 재조회하지 않았다.

## 7. 상점과 과금 정책

핵심 플레이를 건너뛰게 하는 상품보다 **탐험과 Run은 유지하면서 성장 재화 수급 시간을 줄이는 보조 과금**을 기준으로 정리했다.

| 상품 | 현재 지급 | 게임 내 제한 | 카탈로그 가격 | 연결 ID |
|---|---|---|---:|---|
| 몬스터 성장권 | 성장권 1개 | 하루 3회 | 무료 | 무료 서버 지급 |
| 성장 점수 묶음 | 성장 점수 20 | 주간 3회 | 100 WorldCoin | 5YQBPAHHY |
| 성장 코어 묶음 | 성장 코어 3 | 월간 2회 | 200 WorldCoin | GUNTT78HT |

- 최종 주황/황금 결정과 청백/민트 결정 아이콘을 상품 구분에 사용한 작업 기록.
- 유료 상품명·가격·판매 상태는 WorldShopService의 실제 상품 조회를 거치는 구조.
- **실제 플랫폼에 등록된 가격이 정본**이며 위 100/200은 현재 프로젝트 카탈로그 값이다. 이번 보고서 작성에서 플랫폼 가격을 새로 조회하지 않았다.
- PurchaseId 확인, 보상·구매 횟수·영수증 저장, 중복 콜백 ACK 및 재지급 방지 경로.
- 현재 코드는 영수증 표시 순서만 256개로 제한하고 성공 PurchaseId 원장은 삭제하지 않는다. 초기 보고서의 ‘오래된 256건 초과 영수증 삭제’ 설명보다 최신 코드가 우선한다.
- DAILY→WEEKLY, WEEKLY→MONTHLY 정책 변경 시 이전 구매 기록을 고려하는 처리.
- 주간·월간 기간 계산은 현재 코드의 UTC 기준을 사용.

Maker 테스트 구매와 출시 유료 구매는 서로 다른 검증이다. 사용자의 실제 결제 확인 기록은 있으나 환불·운영 장애·장기 영수증 재전달·기간 경계까지 전부 통과한 것으로 기록하지 않는다.

## 8. UI 작업

### 공통 방향

회색 관리자 도구처럼 보이던 UI에서 메이플 계열 인게임 기능창 표현으로 정리했다. 공식 이미지 관찰, 프레임·슬롯·버튼 규칙 정리, 화면별 구조 보정, 광학 정렬 순서로 진행한 기록이 있다.

- Monster Collection: 왼쪽 4열 그리드, 오른쪽 몬스터 상세, 하단 동행 3슬롯.
- 스크롤바를 제외한 콘텐츠 폭 기준으로 그리드 수평 중심 계산.
- 정보 기준선, HP·공격·방어 표시, 고유 능력, 성장 버튼과 비용 정렬.
- Lobby / Adventure / Party / Shop / Run HUD의 컴포넌트 표현 통일.
- 모바일 팝업 배경과 파티 입력 포커스·서버 전달 점검.
- 우측 지도·5슬롯 바 배치와 Run 정보 표시 정리.
- 마을의 파티 찾기·모험 시작 버튼은 공통 스타일을 유지하면서 별도 모양으로 구분하는 작업.
- 불명확한 아이콘 제거, 버튼 깜빡임·눌림 상태·팝업 표시 규칙 보정 작업.
- 다른 메뉴를 열어도 메뉴 버튼이 남는 방향으로 규칙 통합.
- 마을 우측 시작 포탈 제거 요청과 던전 이동 포탈 유지 요청을 구분해 반영한 작업 범위.
- Run 정보 패널은 스킬·강화·RUN 버튼 아래, 강화 상세는 화면 가운데에 여는 방향.
- Run 지도에 남은 시간과 ‘층 - 지역명’을 표시하고 불필요한 숫자·보스동 표기를 정리.
- 특수문자로 정보를 이어 붙이던 설명을 자연스러운 문장으로 바꾸는 작업.

이 목록은 누적 구현 내역이다. 9월 30일 FINAL baseline 화면과 그 후 수정 화면을 동일한 버전으로 간주하지 않는다. 모든 최종 모바일 화면·텍스트 길이·버튼 상태를 이번에 다시 검사하지 않았다.

### Run HUD 동기화

서버 ACTIVE 상태와 클라이언트 HUD 상태가 갈라지는 문제를 조사했다. UI 준비 시 서버 정본 요청, 맵 변경·상태 불일치 시 재동기화, 오래된 다른 맵 응답 무시 및 요청 제한을 추가한 기록이 있다.

당시 3회 연속 Run에서 수동 Broadcast 없이 Objective·HP·Companion·SkillBar·Run 메뉴 표시를 확인했다. 이것은 해당 수정 당시의 **3/3 Maker 검증 기록**이며 모든 후속 버전의 네트워크 회귀를 자동 보증하지 않는다.

## 9. 맵·타일·포탈

- 기존 원작 지역 기반 20지역과 방 콘텐츠를 유지.
- 메이플 아일랜드·리스항구 및 노틸러스의 긴 반복 사선 원인을 공용 모래·물 타일로 식별.
- 타일셋 공유 18맵 중 실제 해당 사선 타일이 칠해진 17맵을 확인.
- 모래를 비방향성 입자, 물을 짧은 불규칙 물결로 교체. 기존 리소스 RUID 유지.
- 타일 배열·충돌·방 연결을 바꾸지 않는 자산 교정 방식.
- 오프라인 대표 맵 전후 이미지 및 계정 리소스 조회 근거가 있음. 해당 사선 교체 보고서의 Maker 검증은 NOT_RUN.
- 마을 진입점과 던전 포탈은 서로 다른 범위로 취급.

이전 사용자가 제기한 포탈 주변 배치·레거시 NPC 노출 문제를 모든 맵에서 최종 해결했다고 이번 문서만으로 선언하지 않는다. 관련 요청과 후속 변경은 최신 맵 확인으로 회귀해야 한다.

## 10. 사운드와 BGM

### VARCO 몬스터 스킬 효과음

- 실제 몬스터 액티브/방어 스킬 66종을 기준으로 사운드 파일명과 제작 프롬프트 설계.
- 추억의 신관은 cast와 empowered_hit을 분리하여 총 67파일.
- 최종 WAV 67 / OGG 67, 48 kHz·mono·16-bit PCM 및 clipping 0의 기존 정적 검증 기록.
- 활성 audioclip RUID 67/67, 파형 보정 신규 RUID 16/16 조회 기록.
- 키메라 3갈래 투사체는 유지하면서 시전음 요청을 1회로 정리.
- 정식기사 C 전용 돌진 경로의 빠진 음향 전달 수정.
- 추억의 신관 강화 타격음은 실제 강화 타격 소비 시에만 별도 호출.
- 우선 36개 파형·코드 판정: PASS 18 / LIMITED 18. LIMITED는 실패가 아니라 청취가 필요한 제한.
- 최신 사운드 보고서의 최종 보정본 Maker Refresh / Build / Runtime Smoke는 NOT_RUN.
- 실제 67개 자연 전투 청취는 완료하지 않았으며 LISTEN_VALIDATION은 NOT_TESTABLE.

리소스 미리듣기에서 기본 효과음까지 무음이었던 사용자 환경 문제와 스킬 연결 문제는 구분한다. 이전에 음소거 설정 해제를 요청한 이력은 있지만, 이 통합 보고서 작성에서 현재 Maker·운영체제 소리 설정을 재검증하지 않았다.

### 가장 최근 지역 BGM 작업

- 원작 `Sound.img` 경로·곡 이름·맵 태그를 공식 리소스에서 확인.
- 37곡을 기존 162맵에 native SoundComponent로 연결.
- 랜덤으로 뽑힌 맵의 지역에 맞는 음악 사용. 음악만 따로 무작위 재생하지 않음.
- 같은 곡의 방 사이에서 KeepBGM 연속 재생 설정.
- 헤네시스 FloralLife, 지하철 Subway, 피아누스 AquaCave 등 세부 구역 분리.
- 기본 BGM 믹싱 0.35. 기존 스킬 효과음 기본값 0.6 유지.
- 공식 BGM RUID 37/37 재조회, BGM 외 맵 데이터 변경 0 확인.
- 별도 옵션창 추가 없음. native 음악/효과음 옵션을 유지하는 방향.
- **새 BGM의 Maker 재생·맵 전환·옵션 슬라이더 반영은 검증 대기.**

### 우선 남길 실제 문제

1. **저장 보호 오류:** 최신 동행 보고서에 Run 시간 종료 후 마을 복귀 시 저장 형식 불일치 / 세션 저장 중단 2건 기록. 원본 보존 보호 동작과 별개로 원인 조사가 필요하다.
2. **기존 Warning:** Legacy Trigger 및 모델 권장값 경고는 완전히 없어지지 않았다. 정상 준비 대기·담당 분리 로그를 낮춘 것과 실제 경고 제거는 구분한다.
3. **검증 숫자의 적용 범위:** 최신 동행 보고서의 Build Error 0 / 기존 Warning 5 / 격리 Runtime Error 0은 당시 구간 결과다. 최신 BGM 반영 후의 숫자는 아직 확인하지 못했다.
4. **문서 노후화:** CURRENT_GAME_STATE는 9월 22일 상태, 일부 인수인계는 더 오래된 구조를 설명한다. 5층·선택권·DEV 상품·3동행 전투 등의 과거 설명은 현재 정책보다 우선하지 않는다.
5. **작업공간 경로:** RootDesk/MyDesk와 Mislocated/MyDesk 경로 문제의 이력이 있다. 최신 커밋은 당시 Maker 파일 위치를 추적했으나 이번 보고서 작성은 구조 복구·이동·삭제 작업이 아니다.

**현재 최신 상태의 전체 Build Error 0 / Runtime Error 0 / 모든 기능 PASS를 선언하지 않는다.**
