# 지형·돌진·투사체 후속 Maker 검증 (2026-09-23)

범위는 스킬 다양성 개편의 환경 호환성 점검이다. 아래 좌표는 MSW 월드 유닛이다. 테스트는 Maker Play에서 수행했고, 검사 계정 저장은 변경하지 않았다.

## 돌진 경쟁 상태 수정

- 수정 전 실제 s_mon_ribbon_pig 시전: 서버 출발점 (0, 0.2)과 표적 (5.5, 0.2)을 준비했지만, 클라이언트 Begin 이후 서버 좌표를 읽어 판정점 (7.4, 0.2)가 되었다. hits=0, 표적 HP 변화 없음.
- PlayerAttack.DashSkill에서 출발점·지형 제한점·시전 맵을 클라이언트 Begin **전에** 고정했다.
- 수정 후 같은 Maker Play에서 판정점 (5.5, 0.2), hits=1, 표적 HP 1000000→999903. 플레이어 실제 위치는 (5.199, 0.2)이었다.
- PlayerDash의 이동 호출에 실제 프레임 delta를 전달하고 돌진/명시적 제어 동안 PlayerControllerComponent.Enable을 임시 해제·복구한다. 수정 후 실제 클라이언트의 평지 돌진은 x=0→3.259(0.2초 돌진 종료), 일반 KNOCKBACK은 x+0.96, STUN 중 방향키 입력 1초는 위치 불변으로 관찰됐다. 일반 피해에는 이 제어가 적용되지 않는다.

## map141 벽 근처 (최종 게임 코드)

- Maker Play map141에서 (0, 0.2)→(0, 10.2) 경로를 계산했다. TraceSkillEndpoint=(0, 3.8), ClampDashTravel=(0, 3.45).
- 실제 붉은 달팽이 돌진: 서버 타격 로그 (0, 3.6), 실제 플레이어 위치 (0, 3.99), 맵은 map141 유지. 외곽 이탈은 관찰되지 않았으나 **타격 중심과 실제 도착점의 약 0.39유닛 차이**가 남았다. 이를 완전 일치 PASS라고 기록하지 않는다.
- 실제 도도 투사체: VFX 로그 0,0.2→0,4.0, 착탄 로그 0,4.0으로 서로 같은 종점이었다. 해당 시전은 자동 조준 가능한 대상이 벽 근처에 있어, 벽 뒤 적 차단까지 증명하지는 못했다.

## 투사체 벽 뒤 광역 피해 수정

- 수정 전 map141에서 도도 투사체는 벽 앞 (0, 3.8)에 착탄했으나, 폭발 반경 2.2 안의 벽 뒤 몬스터 (0, 5.0)에 피해 3을 주었다(HP 1000000→999997). VFX 종점만 지형에 막히고 광역 피해 후보에는 벽 가림이 없던 오류다.
- GameData의 충돌 타일 추적을 재사용해 착탄점 또는 관통 시작점에서 각 피해 후보까지 벽이 없는지 확인한다. PlayerAttack·MonsterAttack의 투사체 착탄/관통 판정에만 적용하며 스킬 계수·범위·VFX 파일은 바꾸지 않았다.
- 수정 후 같은 플레이어 테스트: 벽 뒤 (0, 5.0)는 HP 1000000 유지, 벽 앞 (0, 3.0)은 HP 1000000→999997. VFX와 착탄 로그는 각각 벽 앞 3.8 및 열린 지점 3.0과 일치했다.
- 몬스터 시전자 대칭 테스트: 시전자 (0, 3.0), 벽 뒤 플레이어 (0, 5.0)는 HP 1000000 유지; 같은 쪽 플레이어 (0, 2.0)는 HP 1000000→991051. 이는 높은 큐브슬라임 공격력을 임시 HP로 견딘 테스트이며 데미지 밸런스 승인과는 무관하다.

## 포털·지속 영역

- 격리하지 않은 전수 QA에서 연속 돌진 중 map006→map001 포털 이동이 발생했다. 돌진이 활성 포털의 Trigger에 도달하면 방 전환이 가능하다. 의도된 포털 접촉과 오발을 구분하는 수동 경계 플레이는 **NOT_RUN**. 포털 구조 자체는 이 작업에서 변경하지 않았다.
- DAMAGE_ZONE 예약 타격은 PlayerAttack.UseSpatialSkill에서 시전 당시 맵과 현재 맵이 다르면 중단한다. 최종 Maker NORMAL Run에서 map001의 제노 영역을 예약한 직후 실제 RoomPortal로 map006에 이동했다. 로그 [ZonePortalFinal] before=map001 → [RunPortalRuntime] PASS r_001 --west--> r_006 → after=map006 used=true 사이에 s_mon_zeno tick 로그는 0개, Error도 0개였다. 따라서 정상 포털의 예약 피해 중단은 PASS_RUNTIME이다. 다만 이펙트 개체의 화면상 잔류 여부는 육안 검증하지 않았다. 이전 map141→maptown 강제 텔레포트 실험의 [LEA-3015] CannotLoad 2건은 테스트 방법 오류로 별도 보존하며, 모든 세션이 Error 0이었다고 주장하지 않는다.

## 판정 경계

최종 플레이어 66종 Maker QA는 PlayerAttack.UseSkill·실제 피해/방어·부가 효과·슬롯 소비를 검증했다. QA 중 클라이언트 좌표를 고정해 실수로 포털을 통과하지 않게 했으므로, 66종 모두의 물리 이동을 인증한 것은 아니다. VFX=ACTUAL_PATH_NOT_VISUAL_CERTIFICATION은 리소스 호출 경로를 뜻하며 프레임 미술·화면 판독성 승인이 아니다.
