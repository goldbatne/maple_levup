# Run 진행·동행 목숨·회복 상자 변경 기록

작성일: 2026-10-05

## 커밋 범위

현재 Maker 프로젝트에서 누적된 게임 소스, 데이터, UI, 맵, 최종 버튼·타일 자산을 포함한다.

- 10층 도전, 층별 능력치·보상, S 랭크 해금, Run 제한 시간과 표시.
- 보스 스킬 사용 경로, 몬스터 스킬 모드의 층별 일일 보상 기록, 스킬 자동 지급.
- 성장 점수 묶음 주간 제한과 성장 코어 묶음 월간 제한.
- 마을 메뉴, Run 정보창, 팝업 표시 규칙, 마을 진입 포탈 및 타일 수정.
- 메인 동행의 Run당 목숨 3개, HP·목숨 상태 유지, 회복 상자 효과.
- 기존 Maker 파일 위치와 메타데이터를 현재 디스크 상태대로 추적한다. 이번 커밋 작업에서 추가 파일 이동이나 Maker 구조 복구는 수행하지 않았다.

사운드 파형 작업의 중간 WAV/OGG, 타일 원본 백업·미리보기·후보 파일은 포함하지 않는다.

## 동행 규칙

- Run 시작 시 메인 동행 목숨 3개.
- 치명 피해로 사망하면 목숨 1개 소모. 남은 목숨이 있으면 2초 후 재소환.
- 방 이동은 동행 목숨을 복구하지 않으며 살아 있는 동행의 남은 HP도 유지한다.
- 목숨이 0이면 다음 방에서도 소환하지 않는다.
- 상태는 해당 Run 인스턴스의 사용자별 `RogueCompanionStates`에 기록한다. 월드 세션을 넘어서는 영구 목숨 저장은 제공하지 않는다.
- 회복 상자는 플레이어와 살아 있는 메인 동행을 회복한다. 목숨이 부족하면 20% 확률로 1개 회복하며 최대 3개다.
- 0개에서 1개로 회복하면 메인 동행을 다시 소환할 수 있다.
- HUD는 동행 HP와 남은 목숨을 표시한다.

## 알려진 문제와 검증 구간

이전 전체 Play 세션에서 Run 시간 종료 후 마을 복귀 중 저장 보호 오류 2건이 관찰되었다.

- `[PlayerDB] 로그라이트 저장 형식 불일치 — 원본 보존`
- `[PlayerDB] 로드 실패 — 이 세션은 저장하지 않는다 (세이브 보호)`

이는 최종 격리 스모크의 Runtime Error 0과 별도다. 전체 세션의 Runtime Error가 0이었다고 주장하지 않으며 저장 보호 문제는 후속 조사 대상으로 남긴다.

## 커밋 준비 정적 확인

- 현재 추적 대상 model / directory / userdataset / codeblock JSON 209개 파싱 성공.
- 해당 파일들의 중복 EntryKey 0.
- RootDesk의 mlua에 대응하는 codeblock 누락 0.
- SkillTable CSV는 사운드 PR 기준 내용과 동일하며 현재 Maker 경로로 이동한 상태를 포함한다.
- Maker가 저장한 스크립트의 들여쓰기·주석·CRLF 변화가 포함되어 있다. `git diff --check`의 공백 경고는 별도로 남기며, 이를 게임 Build Error로 취급하지 않는다.

이 문서는 전체 프로젝트 또는 전체 67종 사운드 청취 PASS 선언이 아니다.
