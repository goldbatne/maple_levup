# Mega Area 랜덤 조우 개편 요약

## 적용 결과

- 기존 20 Area를 5개 Mega Area로 재구성했다.
- 8~10칸 주 경로와 2~4개 선택 가지를 Seed로 생성한다.
- 각 경로는 구성하는 네 하위 Area를 모두 포함하며 지정 순서를 따른다.
- 일반방은 6~10체, 2~4종 혼합 조우다.
- 첫 능력은 확정, 이후 적격 처치 능력 획득은 10%다.
- Run 고유 `OwnedSkillPool`과 5칸 랜덤 재고를 사용한다.
- 5초마다 빈칸 하나 공급, 중복 허용, 성공 사용 시 한 칸 소비, 플레이어 쿨다운 없음.
- 포션은 독립 5% 드롭, 즉시 최대 HP 25% 회복이다.
- NORMAL / MONSTER_SKILL 선택을 지원한다.
- 모든 Mega Area는 지정된 4종 중 Seed 기반 보스 한 종으로 끝난다.
- Area 순서 기반 능력치 증가는 제거하고 HP 240 / ATK 24 / DEF 6 공통 기준을 사용한다.
- 실제 HP 감소량 기반 개인 피해 원장을 Clear/Fail 결과에 사용한다.

## 보호 사항

- 66개 기존 액티브/방어 스킬의 고유 효과·수치·VFX·몬스터 연결은 변경하지 않았다.
- 원본 맵, 몬스터 모델, 보스, 스킬 아트를 재사용했다.
- 기존 사용자 미커밋 변경을 reset/revert하지 않았다.
- git commit/push는 수행하지 않았다.

## 미검증/제약

- 독립 2~4클라이언트 실제 협동: `BLOCKED_RUNTIME_MULTIPLAYER`.
- 모든 중간 통로를 사람 입력으로 걷는 5개 Area 완주: `NOT_RUN`; 실제 시작·첫 조우·보스·Clear는 검증.
- 서버 프로세스 재시작을 넘기는 중간 Run 복원은 구현하지 않음. 영구 기록과 InstanceRoom Run 상태는 분리됨.
