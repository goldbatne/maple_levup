# T61 몬스터 스킬 UUID 품질 개선 — 메이플 아일랜드~노틸러스

> **후속 교정:** T61의 공식 클립 우선 배치는 일부 스킬에서 검·사슬·직업기 형상이 몬스터 설정과
> 충돌했다. 현재 정본은 [T62 의미 정합성 교정](작업보고_몬스터스킬_의미정합성_T62.md)이며,
> 스킬 이름과 몬스터의 신체·서식지·이야기를 우선해 전용 창작 스프라이트로 교체했다.

## 결론

현재 구현 범위의 액티브 몬스터 스킬 23종을 MSW 공식 `animationclip` 기반으로 이관했다.
일반 몬스터는 짧고 읽기 쉬운 1단 연출, 지역 보스는 2~3단 연출을 사용한다. 패시브 7종은
시전 행동이 아니므로 기존 규칙대로 이펙트·소리·투사체를 재생하지 않는다.

이 작업은 직업 스킬 전체를 복제하지 않는다. 공식 스킬팩에서 `effect`·`hit`·`tile`처럼
캐릭터 몸이 포함되지 않은 프레임 클립만 골라 몬스터의 색·몸·행동·지역 이야기에 맞게
크기와 시간차를 다시 구성한다.

사용하므로 이번 이관 대상에서 제외했다.

## 데이터 규격

- `SkillTable.csv`의 `layer_*` 10개 컬럼을 정본으로 사용한다.
- T61 당시에는 모든 레이어의 `resource_type`이 `animationclip`이었으나, T62부터는
  설정상 고유 형상이 필요한 스킬을 프로젝트 전용 `sprite`로 교체한다.
- 일반 몬스터 1레이어, 마노·셰이드 3레이어, 머쉬맘·스텀피·파우스트·주니어 발록 2레이어다.
- 레이어가 있는 스킬은 과거 단일 커스텀 스프라이트 경로인 `effect_ruid/effect_style`을 비웠다.
- 스텀피·파우스트의 원본 투사체와 몬스터별 기존 효과음은 유지한다.

## 검증

- MSW 리소스 검색 API로 선택 UUID의 유형과 원본 팩을 대조했다.
- `verify-content-coverage.cjs`: 액티브 무연출 0, 패시브 연출 잔여 0, 잘못된 레이어 레시피 0.
- Maker Refresh 후 클라이언트 데이터에서 23종 레이어 수가 모두 설계값과 일치했다.
- 런타임 시각 확인: 화염 폭발, 보호막, 잎 회오리, 물결, 파우스트 저주, 주니어 발록 화염.
- 마노 1차 후보의 보라색 용 형상은 설정 불일치로 즉시 폐기하고 물결·잎·무지개 조합으로 교체했다.
