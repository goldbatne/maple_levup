## 목표

노틸러스 다음 구간인 Lv61~100을 슬리피우드, 오르비스, 엘나스 산맥, 아쿠아로드 네 지역으로 확장한다. 기존 지역과 같은 8방 분기 구조, 일반 4종+보스 1종, 포획 스킬·장비 드랍·보스 규격을 유지한다.

## 작성된 것

- 지역 4개와 맵 32개: `map071`~`map107`(각 지역 보상방 `a` 포함)
- 공식 MSW 몬스터 팩 기반 모델 20종
- 신규 포획 스킬 20종: 지역별 액티브 3종·패시브 2종
- 신규 일반 장비 20종과 MSW 아바타 아이콘
- 지역별 커스텀 타일 4종, 전체 16종과 전용 tileset 4개
- Lv60/70/80/90 지역 해금, 직전 지역 보스 스킬 보상방 게이트
- 스킬 장착 창 50칸 확장

- `node docs/tools/verify-area07-area10.cjs`: 32맵 448타일, 상호 연결, 위험 타일 경계, 모델 20종 통과
- `node docs/tools/verify-content-coverage.cjs`: 50몬스터·50스킬·53아이템·12보스 및 UI 연결 통과
- 지역 선택 창은 20칸, 월드맵은 12버튼이라 새 지역 4곳을 수용한다.
- 가방은 분류별 최대 24종으로 36칸 안에 들어간다.
- Maker에서 32맵 전부 목표 맵 전환과 방별 스폰을 확인했고 런타임 오류는 0건이다.
- 네 보스의 HP ×10·300초 HUD와 공격 발동을 확인했다.
- 타우로마시스 재입장 시 HP·시간이 초기화됐고 피아누스 블루마린은 확률 1.000으로 확정 드랍됐다.
- 런타임 신규 스킬 20/20, 스킬 UI 셀 50/50을 확인했다.
