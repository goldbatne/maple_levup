# 인수인계 — 현재 작업만

> 갱신: 2026-09-07 · T58 `area_00` 진행 중

## 목표

기존 첫 지역 앞에 메이플 아일랜드·리스항구를 넣고, 이후 지역의 레벨 대역을 10씩 뒤로 민다. 저장 호환성을 위해 기존 `area_id`, 방 ID, 맵 ID는 유지한다.

## 작성된 것

- `area_00`과 방 8개: `r_001`, `r_002`, `r_003`, `r_00a`, `r_004`, `r_005`, `r_006`, `r_007`
- 맵 8개: `map001`, `map002`, `map003`, `map00a`, `map004`, `map005`, `map006`, `map007`
- 빨간 달팽이·마노 데이터와 모델
- 지역 순서와 Lv10/20/30/40/50 해금 이동
- 메이플 아일랜드·리스항구용 모래·숲·해안 타일 구성

## 확인된 것

- `node docs/tools/verify-content-coverage.cjs`: 통과
- `node docs/tools/verify-area00.cjs`: 파일 구조 검사는 통과
  - RectTileMode 1
  - 8맵 모두 448타일
  - 방 연결 상호 일치
  - 빨간 달팽이·마노 모델 존재

## 남은 것

1. Maker Refresh로 새 모델·맵 엔트리를 등록한다.
2. Maker에서 저장해 SectorConfig에 `area_00` 맵 8개를 반영한다.
3. 빌드 로그 0건을 확인한다.
4. Play에서 시작 지역, 8방 이동, 스폰, 모래·숲·해안 화면, 마노 보스전과 드랍을 확인한다.
5. 통과 후 `프로젝트_현황.md`의 `area_00`을 런타임 검증 완료로 바꾸고 T58을 커밋한다.

## 이번 점검에서 발견한 기존 이슈

- Maker `GameDataVerify`가 `r_job_02 south → r_29`의 역방향 연결 누락을 오류로 보고한다. 현재 `r_29.north`가 비어 있다. 보우마스터 히든 보스의 의도한 입구 방향을 확인한 뒤 양방향 연결을 맞춰야 한다.
- Build Console 경고 2건이 남아 있다.
  - `model://mano`: `MovementComponent.InputSpeed` 권장값 경고
  - `model://bowmaster`: `MonsterAttack.AvatarAttackPlayRate` 권장값 경고
- 다수 포탈의 Legacy 경고와 클라이언트에서 RectTileMap 자식을 처음 찾지 못했다가 재시도하는 경고가 있다. 이번 문서 개편에서는 동작을 바꾸지 않았다.

## 주의

- 현재 작업 트리에는 T58 데이터·맵·모델·UI/스탯 관련 미커밋 변경이 함께 있다. 문서 정리 때문에 이를 되돌리거나 덮어쓰지 않는다.
- 정적 검사는 Maker 등록을 증명하지 않는다. SectorConfig 누락 상태에서 완료라고 쓰지 않는다.
