## 현재 목표

Lv1~200 지역 타일은 소재상 대체로 지역과 맞지만, 넓은 평행선·사선 반복과 지역 간 동일 지형 템플릿 때문에 가독성과 지역성이 부족하다. 다음 맵 작업은 `T69 지역 타일 지역성·가독성 전수 교정`이며 상세 범위와 우선순위는 `타일_지역매칭_전수검수_T69.md`를 기준으로 한다.

## 기존 별도 이슈

- `r_job_02 south → r_29`는 히든 보스방의 단방향 복귀 연결이다. 일반 지역의 양방향 연결 검사에서는 제외한다.
- `GameDataVerify.mlua`의 구형 규칙을 현재 규격에 맞춰 전직 보스방 단방향 귀환과 `pants`·`shoes`·`cape` 장비 슬롯을 허용했다. 현재 Maker 프로세스는 Refresh·Save 후에도 이전 스크립트 캐시를 실행했으므로 다음 완전 재실행에서 해당 오탐 15건 소멸을 확인한다.
- Build Console에는 기존 마노·보우마스터의 권장값 경고가 남아 있다. 신규 엘리쟈·설산의 마녀 이동속도는 권장 하한 1.2로 맞췄다.
- T65 첫 Refresh에서 신규 `.tileset` 4개가 `Mislocated`로 이동해 해당 entry ID의 14:13 오류가 Build Console 이력에 남았다. 파일과 참조는 모두 제거하고 기존 4개 tileset의 5~8번 슬롯을 확장하는 방식으로 교체했다. 현재 32맵 Play는 정상이며 저장소에 폐기 ID 참조는 0개다.
