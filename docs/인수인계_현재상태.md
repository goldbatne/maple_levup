# 인수인계 — 현재 상태

- 갱신: 2026-08-08 (T10-4 완료 시점)
- 대상: 이 프로젝트를 **처음 받는 사람 또는 AI**

> **이 문서의 목적 하나.** 기획서는 "이렇게 만들 것"을 적은 문서고, 코드는 "이렇게 만들어진 것"이다.
> 둘은 지금 **9군데에서 다르다** — 문서에 있으나 없는 것 7건(A~G) + 문서 근거 없이 있는 것 2건(H·I).
> 기획서만 읽고 작업하면 없는 기능을 있다고 가정하게 된다. 그 차이를 3절에 모아 둔다.
>
> 태스크를 완료할 때마다 이 문서도 갱신할 것 (CLAUDE.md 문서 갱신 규칙).

## 1. 한 문단 요약

방 5개(`r_01`~`r_05`)를 오가며 몬스터를 잡아 레벨을 올리고, 스탯이 모자라면 문이 안 열리고,
몬스터를 포획해 스킬을 얻고, Lv30 + 보스 격파를 채우면 환생해 직업을 고르는 —
**수직 슬라이스가 전 구간 동작한다.** T0~T10 코드 태스크가 전부 끝났고,
남은 것은 대표의 체감 판정과 `monster_atk_base` 수치 조율뿐이다.

## 3. 문서에 있으나 구현되지 않은 것 ⚠

**기획서를 읽을 때 이 표를 옆에 두어야 한다.**
모두 슬라이스 범위를 벗어난다고 **AI가 자체 판단**한 것이며, 대표의 개별 승인 절차를 거치지 않았다.
(승인을 받은 설계 변경 10건은 CLAUDE.md "설계 변경 이력"에 있고, 그것들은 문서에 이미 반영돼 차이가 없다.)

| # | 문서 | 실제 | 왜 |
|---|---|---|---|
| A | 기획서 §3.2 **게이트 3종** | `RoomGate.mlua`에 `stat`/`key`/`rebirth` 분기가 **전부 구현돼 있다.** 그러나 `RoomTable`의 방 5개 중 `gate_type=rebirth`인 방이 **0개** → 환생 게이트는 게임에서 만날 수 없다 | 슬라이스 방 5개 설계 때 배치하지 않음. **한 줄 추가로 살릴 수 있다** |
| B | 기획서 §4.5 랜드마크 **구역 개방** | `LandmarkTable`에 `area,area_02` 있고 `Rebirth.mlua`가 `UnlockedAreas`에 기록·저장까지 한다. 그러나 `RoomTable`에 **area 컬럼 자체가 없고** area_02의 방도 없다 → 열려도 갈 곳이 없다 | 슬라이스 범위가 방 5개 |
| C | 기획서 §4.7 **스탯 티어 상승 5→6→7** | 미구현. `LandmarkTable`에 `tier` 보상 타입 없음 | 캡이 Lv30 1구간이라 티어 상승 지점이 없음 |
| D | 기획서 §4.5 보상 중 **캡 확장** | 미구현 | 위와 같음 |
| E | 기획서 §4.4 **링크스킬식 계승** | `JobTable.inherit_skill_id` 컬럼과 파싱은 있으나 **쓰는 로직이 없다** | "직업 마스터" 개념이 슬라이스에 없음 |
| F | 기획서 §4.2 **컬렉션 → 패시브 해금** | 미구현 | 작업지시서에 **"확장 단계"로 명시적 연기** — 차이가 아니라 계획된 순서 |
| G | 기획서 §4.7 LUK의 **드랍률** 역할 | 드랍 시스템 자체가 없다. LUK은 포획률 + (T10-4 이후) 스킬 계수에만 작용 | 아이템/드랍이 슬라이스 범위 밖 |

## 4. 임시 처리 · 정리 후보

### 4.1 데이터 테이블 밖에 있는 수치

CLAUDE.md 규칙 3(수치 하드코딩 금지)에 걸린다. CSV만으로 밸런스 패치를 하려면 옮겨야 한다.

목록은 `docs/밸런스_확정수치.md` §1 "아직 CSV 밖에 있는 값" 표가 정본이다 (5건).
요약하면 i-frame 1초 · 몬스터 공격 주기 0.5초 · 추격 범위 6.0 · 히트박스 크기 · 플레이어 HP 1000.
앞 3개는 CSV로 옮길 수 있고, 뒤 2개는 옮길 수 없다(종별 값 / 엔진 기본값).

### 4.2 규칙 미준수

`PlayerAttack.mlua`와 `MonsterAttack.mlua`에 **실행공간 상단 주석(`-- @서버`)이 없다** (CLAUDE.md 규칙 1).
같은 MSW 샘플 유래인 `PlayerHit.mlua`에는 붙어 있다.

### 4.3 미사용 잔존 파일 11개

MSW 워크스페이스 baseline(`00580a4`)에서 유입된 샘플 스크립트. **어떤 모델·맵에도 부착돼 있지 않고**
호출부도 없다 (모델 8개 전수 확인).

```
RootDesk/MyDesk/  Monster.mlua  StateChaseMonster.mlua  StateMoveMonster.mlua
                  StateTypeChase.mlua  StateTypeWander.mlua
                  ConditionHasTarget/IsAlive/IsDead/NoTarget.mlua

```

삭제 여부 미결정. `MonsterAttack` / `PlayerAttack` / `PlayerHit`도 같은 출신이지만 **이 셋은 실제로 쓴다.**
