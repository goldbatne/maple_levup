- 생성 대상: `m_mushroom`, `m_mushmom`만 처리
- 제외 유지: 달팽이, 파란 달팽이, 뿔버섯 패시브 및 AREA 01 나머지 몬스터
- 미수행: Resource Storage 등록, AnimationClip 생성, SkillTable 연결, Maker 반입
- 자동 포맷 처리: 등분 분할, 목표 크기 정규화, 중성 RGB 배경의 알파 복구만 수행
- 전체 로컬 처리 시간: 51.2초
