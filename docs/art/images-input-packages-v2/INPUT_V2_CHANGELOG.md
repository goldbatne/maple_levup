# INPUT V2 CHANGELOG

확정 monster/skill WHAT과 게임 파일은 변경하지 않았다. 기존 INPUT ZIP도 덮어쓰지 않았다.

## 공통

- RECENT_SECONDARY 자동 최신 승격 제거; 시기 근거 없으면 미확인 유지.
- 183개 라이브러리에 role_classification/role_basis 추가, 본체 RUID를 EXCLUDE_STYLE로 분리.
- 출력 루트를 AREA_XX_IMAGES_OUTPUT로 통일.
- 역할별 VFX, 엔진 이동/FlipX/offset·drift 단위, 피해 판정 시점을 실제 코드 기준으로 명시.
- 원본 시트·분할 좌표 보존, 실제 alpha/잘림/셀 조각 검사, 자동검사와 사용자 승인 분리.
- Monster model→RUID→MONSTER_IMAGE 출처·해시 기록.
- AREA 00 동일 ID 승인 자산을 독립 패키지에 바이트 복사하고 해시 기록.
