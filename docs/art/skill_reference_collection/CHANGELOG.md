# 공식 스킬 디자인 참고 INPUT 개편

- 확인된 문제: 기존 MASTER PROMPT가 MSW 자료를 “역할 분리와 시간 구조만” 참고하도록 제한했다. 실제 디자인·명암·재질·발광·입자·ICON 표현을 함께 관찰하는 지침으로 수정했다.
- 기존 AREA03 슬라임 참조가 암살 VI·솔 야누스 황혼 중심으로 지정되어 있었다. 새 연결표는 물 표현과 방호 단계 등 참고할 표현을 분리하며, 고정 점액 소재를 그대로 유지한다. 기존 지정 목록은 보조 자료로 보존했다.
- 20개 운영 INPUT ZIP의 `reference_resource_design`에 공식 표시용 PNG/GIF, 추출 PNG, 출처 JSON, 104개 스킬 연결표를 추가했다. AREA06은 기존 인덱스에서 제외된 상태를 유지했다.
- 17개 표현 참조 그룹 / 공식 PNG·GIF 63개. 실제 몬스터 PNG 및 게임 ID·효과·소재·동작·역할·출력 규격을 보존했다.
- 공식 자료의 흰 배경·GIF 팔레트 제한을 명시했다. 프리뷰 추출 PNG를 엔진 원본 알파로 설명하지 않았다. 현재 조회 가능 여부와 최신 라이브 리비전 확인을 구분했다.
- 개편 전 INPUT ZIP/TXT는 검증 중 `backups/INPUTS_BEFORE_*.zip`에 임시 보존했다. 개편 후 해시는 정규 INPUT 폴더의 `ALL_AREAS_INDEX.csv` 및 각 ZIP의 `INPUT_FILE_HASHES.csv`에 갱신했으며, 중복 백업은 커밋 정리 단계에서 제거했다.
- 신규 OUTPUT 생성·기존 OUTPUT 편집·게임 데이터 변경·실행 검증·커밋은 수행하지 않았다.
- 공통 라이브러리의 수집 완료 범위는 `COLLECTION_REPORT.json`에서 확인한다. 다운로드 중에는 `download_state.json`과 `downloads.jsonl`이 재개 기록이다. `download_archive.py`로 누락 수집을 이어갈 수 있다.

참조 이미지가 포함되어 있다는 사실만으로 외부 제작 결과의 디자인 일치나 품질 통과를 보장하지 않는다. 실제 생성 입력과 최종 아트를 별도로 확인해야 한다.
