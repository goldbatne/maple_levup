- 공격 64종, 방어 3종, 패시브 35종

## 검증 중 수정한 결함

### `s_mon_mutant_stone_mask` — 발굴지의 석면

- 문제: 명세가 `passive_stat=DEF`인데 검증기와 컬렉션 파생 수치 계산이 `STR/DEX/INT/LUK`만 허용함.
- 수정: `DEF`를 유효한 포획 패시브로 허용하고 `GetCollectionBonus("DEF")`에 정액 방어력으로 반영.
- 실측: 해당 카드 1장 임시 보유 시 총 방어력 `710 → 711`, 원복 후 기존 값 복원.

### 범위형 투사체 5종

- 대상: 고목의 생기탄, 저주의 인형, 융합체의 산성 포격, 태륜의 쌍권풍, 기억 포식.
- 문제: `target_mode=area`와 설명은 착탄 지점 범위 공격인데 단일 투사체와 같은 반경 `0.8`을 사용함.
- 수정: 범위형만 `max(기본 반경, min(사거리 × 0.4, 2.5))`를 사용. 단일 대상 7종은 `0.8` 유지.
- 실측: 고목의 생기탄 `반경 2.00 → 1명` 타격, 별빛 탄환 `반경 0.80` 유지.
