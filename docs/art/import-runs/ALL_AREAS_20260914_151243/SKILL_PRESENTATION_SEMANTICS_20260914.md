# 전 Area 몬스터 획득 스킬 의미·배치 보정

기준은 “해당 몬스터가 메이플스토리에 새로 추가되어 고유 스킬을 쓴다면”으로 읽히는 것이다. 기존 반입 PNG·RUID·스킬 ID·판정 수치는 유지하고, 공통 실행 경로의 연출 위치와 UI 표기만 보정했다.

## 적용

- 공격 스킬: 기존 원형/착탄 판정은 유지한다. 직접 공격 VFX는 실제 명중 대상들의 중심에서 재생하며, 빗나가면 입력 방향의 사거리 안쪽에서 재생한다.
- 돌진 스킬: 시작 순간부터 시전자 몸을 따라 VFX를 재생한다. 계산된 도착 예정점에서의 중복 VFX는 제거했으며, 기존 도착 판정과 쿨다운은 유지한다.
- 투사체 스킬: `sprite_sequence`가 있으면 해당 스킬의 신규 프레임을 목표까지 이동시킨다. 기존 `projectile_ruid`는 투사체 판정 분기용으로 남지만 범용 돌·구체 그림으로 표시하지 않는다.
- 방어·버프 스킬: 시전자 몸 중심에 높은 `OrderInLayer`로 표시하며, 지속 중 시전자를 따라간다.
- 스킬 설명: 공격은 현재 중복 강화가 반영된 `피해 N%(기본 M%)`, `최대 N마리` 또는 `범위 내 전체`, 범위와 쿨다운을 표시한다. 방어는 효과율과 지속 시간을 표시한다.

## 데이터 검사

- 몬스터 스킬: 공격 64, 방어 3, 패시브 35.
- 공격 64개 중 VFX 미연결: 0.
- 레거시 `projectile_ruid` 보유: 12.
- 위 12개 중 `sprite_sequence` 미보유: 0.

## Maker 검증

- Build: 이번 변경 관련 오류·정보 경고 0. 기존 `model://mano InputSpeed`, `model://bowmaster AvatarAttackPlayRate` 경고 2개는 유지.
- 격리 런타임: 오류 0.
- 양성 로그:
  - `포자 살포 ... 타격 지점`
  - `푸른 껍질 ... 몸 오버레이`
  - `고목의 생기탄 신규 프레임 12장 ... → ...`
  - 정지 입력 검증: `야수의 그림자 돌진 ... 이동 동기화 0.0,0.0`; 계산된 도착점 VFX 없음.
  - 세 이펙트 모두 종료 로그 확인.
  - UI: `[공격] ... 피해 132%(기본 110%) 범위 내 전체 범위 2.5 쿨 4초`.

## 남은 확인

- 비치명/치명 피격과 포획 흐름은 코드를 변경하지 않았으며 이번 격리 연출 검증에서는 다시 실행하지 않았다.
- Play 시작 시 기존 데이터 오류 `s_mon_mutant_stone_mask passive_stat='DEF'`가 별도로 발생한다. 이번 연출 변경에서 생긴 오류는 아니며 후속 데이터 보정 대상이다.
