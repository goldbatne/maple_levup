# AREA01·02 지정 레퍼런스 보정 후보

외주 OUTPUT을 INPUT과 AREA00 기준에 대조한 후보입니다. 개인 취향을 새 기준으로 삼지 않습니다. AREA01 달팽이 2종은 동일 스킬의 00 후보를 재사용했고, 버섯 3종의 부족한 마감을 제작했습니다. AREA02는 기존 디자인을 보존하고 뼈 무덤의 분리된 상단 조각과 마지막 잔존 fade 후보만 처리했습니다.

BEFORE_AFTER.html을 열면 같은 배경과 표시 크기로 비교할 수 있습니다. ZIP 안에 최종 PNG, Preview, Manifest, RESULT_INFO, 변경 해시, 검증 및 생성/변환 기록이 있습니다. 원본 ZIP과 게임 데이터는 변경하지 않았고 실행 검증은 하지 않았습니다. 자동 승인본이 아닙니다. AREA02의 마지막 잔존 감소는 사용자 판단 대상입니다.

프로젝트에는 이 폴더의 최종 6개 파일만 저장하며 중간 추출 파일은 임시 폴더에 보관했습니다.
