# AREA00~02 디자인 확정 전 검증

검사 범위: 현재 최종 보정 후보 ZIP 3개. 원본 외주 ZIP과 구분. 이미지/게임 데이터 수정 없음. 아트 확정 권장과 사용자 승인 및 게임 반입 완료는 별개다.

**결론: 18항목 중 15항목은 디자인 확정 권장. 머쉬맘 1항목은 소재 읽힘 보완, 파이어보어 1항목은 실루엣 구분 판단, 스텀피 1항목은 발사/타격 동작 연결 확인이 남는다.**

164 PNG(146 VFX +18 ICON)를 실제 디코딩. RGBA·투명/반투명 픽셀 존재, alpha>0 기준 중앙85% 및 경계 접촉 검사 이상 없음. 모든 시퀀스를 순서대로 정지 프레임으로 확인했고 대표 프레임을 검정/회색/흰색에 합성했다. 주요 형상70% 의미론적 정량분리·실시간 재생 관찰·정밀 피봇·게임 내 크기/혼합/타격동작은 NOT_CHECKED. PNG에는 타이밍이 없으며 뷰어는 INPUT 선언 100ms/80ms를 사용한다.

지난 RUID 실조회에서 18개 항목 이름/외형 일치 및 불투명 RGB 일치를 확인했다. 이번 판단은 그 결과와 별도로 실제 VFX/ICON을 GENERATION_SPEC에 대조했다.

AREA00과 AREA01의 달팽이 두 스킬은 후보 PNG 해시가 전부 일치한다. 패시브 VFX 수량 지시와 ICON-only 역할 충돌은 기존 INPUT 문제이며 누락된 비필수 VFX를 재제작 사유로 삼지 않는다.

## 근거

### 00 달팽이 / 이슬 미끄럼길
낮은 점액 띠·물방울·미끄러지는 긴 축과 ICON이 연결된다. 입체 하이라이트와 점액 재질이 읽힌다. 청록/연두 비중은 기존 표현을 보존할 수 있다.

### 00 파란 달팽이 / 푸른 껍질
아래에서 위로 감싸는 나선형 반원 보호막. 청색 껍질 ICON과 모티브 연결. 물막처럼 보이는 해석은 명세의 보호막과 양립한다.

### 00 빨간 달팽이 / 붉은 껍질 돌진
붉은 나선·오른쪽 잔상·충돌광과 분해 흐름이 연결된다. 원반을 고체가 아닌 에너지 잔상으로 표현한 기존 보정 방향을 유지할 수 있다.

### 00 마노 / 마노의 무지개 파동
진주 껍질 고리·낮은 무지개 파문과 ICON이 명세에 맞는다. 팽창 뒤 마지막 fade는 관찰되나 새로 그린 해체라고 해석하지 않는다.

### 00 슬라임 / 끈적한 몸통
눌린 젤리→큰 점액 튐→작은 덩어리로 돌아오는 탄성이 읽힌다. 덩어리 잔존은 기존 해석으로 보존 가능하며 오류로 간주하지 않는다.

### 01 달팽이 / 이슬 미끄럼길
AREA00 동일 스킬과 PNG 바이트가 전부 같음. 별도 재제작 필요 없음.

### 01 파란 달팽이 / 푸른 껍질
AREA00 동일 스킬과 PNG 바이트가 전부 같음. 별도 재제작 필요 없음.

### 01 주황 버섯 / 포자 살포
베이지색 세 구름과 연두 점 포자가 출현·성장·분리·fade한다. 명세 핵심이 읽히며 ICON도 세 덩이/점 입자 연결. 00 점액과 재질을 똑같이 만들 필요는 없다.

### 01 머쉬맘 / 머쉬맘의 포자 충격
하강 핵→지면 접촉→갓 모양 확장→분해의 순서는 맞다. 그러나 F04/F05의 밝은 금색 테두리와 불꽃 같은 상승광이 포자보다 화염 폭발로 읽힐 소지가 크다. 현재 팔레트 자체는 INPUT에 맞으므로 색을 갈아엎기보다 구름의 무광 중간톤·분말 가장자리·포자 파편을 강화할 것을 권장. 내가 만든 후보도 예외 없이 보류.

### 01 뿔버섯 / 단단한 뿔
상아 뿔·갈색 갓 곡선·짧은 반사광이 INPUT 그대로 읽힌다. 실제 몬스터의 청회색 갓과 다른 색은 INPUT 지정이며 UUID 오류가 아니다. 패시브 ICON만 필수.

### 02 스톤골렘 / 암석 피부
바위 판이 감싸고 균열광이 절정에서 밝아진다. 암석면과 ICON 연결이 좋다. 불투명 돌 재질을 00 물막처럼 바꾸지 않는다.

### 02 엑스텀프 / 도끼 휘두르기
철회색 도끼날 호·갈색 나무 파편·오른쪽 충돌점이 명확하다. 실제 도끼 물체 전체를 그리지 않아도 명세는 궤적을 허용한다.

### 02 다크 엑스텀프 / 어둠의 뿌리
지면에서 솟는 흑갈색 뿌리와 보라 에너지가 명세에 맞는다. 나무 재질과 수직 성장 흐름 유지 권장.

### 02 와일드보어 / 저돌 맹진
두 갈래 어금니형 전방 궤적·흙먼지와 ICON이 맞는다. 성장→타격→파편 흐름이 보인다.

### 02 아이언 호그 / 강철 발굽
금속 반달 발굽·지면 충격과 ICON 연결이 맞는다. 참고 VFX는 반입 필수가 아니며 ICON으로 확정 판단.

### 02 스켈레톤 지휘관 / 뼈 무덤
비스듬히 솟는 뼈기둥·흙 파편·교차한 뼈 ICON이 맞는다. 상단 조각을 처리한 후보에서 주요 뼈의 연결은 유지된다. 실제 뼈를 발광 리본으로 바꿀 이유 없음.

### 02 파이어보어 / 화염 돌풍
불꽃 소재·명암·ICON 연결은 맞는다. 다만 둥근 나선/전방 충돌이 AREA00 붉은 껍질 돌진과 유사하다. 다른 스킬임을 더 강하게 드러내려면 낮고 길게 휘는 불꽃 혀를 강조. 명백한 오제작 확정은 아니며 동시 비교 후 유지 가능한 판단 항목.

### 02 스텀피 / 고목의 생기탄
나이테→싹→씨앗 탄의 소재·마감은 맞다. F06~F08 오른쪽 발사 다음 F09에서 중앙 지면 폭발로 전환된다. 한 고정 피봇의 단일 clip으로 쓰면 위치가 되돌아온 것으로 보일 수 있다. 발사/타격 역할 연결을 확인할 때까지 전체 동작 확정은 보류; 원화 전량 재제작 사유는 아님.
