# AREA 00~02 몬스터 RUID 실조회 대조

현재 canonical INPUT 18항목(고유 RUID 16개)을 공식 리소스 API에서 직접 조회했다. 16개 모두 mob animationclip으로 존재하며 공식 이름과 포함 MONSTER_IMAGE의 몬스터 정체성이 일치한다.

INPUT PNG와 공식 GIF는 바이트/전체 RGBA가 같지 않다. INPUT은 흰 배경을 투명 처리한 이미지이며 선택 프레임 차이도 있다. 좌우 비교로 형태·색·얼굴·장비를 확인했다. exact pixel match로 보고하지 않는다. 픽셀 오차는 참고용이며 이름/시각 대조와 함께 사용했다.

이번 결과는 몬스터 reference identity 검증이다. 게임 .model의 런타임 할당 UUID, 스킬 아트의 품질/효과 적합성, 사용자 승인 여부를 새로 인증하는 검증은 아니다. 기존 파일/게임 데이터 수정 없음.
