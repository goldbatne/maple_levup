## 통일해야 하는 마감과 허용 차이

- 외곽은 곡선/면을 읽히게 정돈한다. 돌·금속·목재의 날카로운 모서리와 결은 허용한다. 문제 후보의 굵은 픽셀 계단은 원본 해상도에서 반복되는 제작 마감 차이이며, 단순히 확대했을 때 생기는 1픽셀 계단만을 뜻하지 않는다.
- 명암은 소재의 부피 또는 얇은 면을 설명한다. AREA00 빨간 달팽이처럼 분리된 색면도 허용한다. 모든 대상에 광택, 어두운 외곽, 밝은 핵을 강제하지 않는다.
- 발광은 불투명 재질과 분리해서 본다. 얇은 날카로운 광선과 부드러운 반투명 잔광의 관계를 비교한다. 무광 뼈·흙을 물방울처럼 빛나게 만들지 않는다.
- 파편·입자는 역할에 맞는 모양과 밀도를 허용한다. 사각 블록/회로의 사각 입자 자체가 잘못은 아니다. 액체·금속·빛의 전체 윤곽과 음영까지 공통으로 거친 픽셀 단위로 바뀌는지는 따로 본다.
- ICON과 VFX는 같은 소재·명암·반사의 계열로 읽히는지 비교한다. ICON의 단순화, 허용된 목마 머리/가면/뿔/인형은 인정한다. CAST에서 금지된 본체 표현과 ICON의 허용 모티브를 혼동하지 않는다.
- 시간 흐름은 모든 실제 프레임을 순서대로 확인한다. 공격의 형성/발현/해체와 참고 모티브의 짧은 호흡은 서로 다른 계약이다. PROJECTILE은 엔진 이동·회전 규칙과 고정 로컬 중심을 유지해야 하며 스타일 통일을 이유로 동작을 바꾸지 않는다.

## 표시 조건과 판정의 한계

원화 PNG를 RGB(32,38,48) 배경에 원본 픽셀 1:1로 합성했다. ICON은 256px, VFX는 각 계약의 256/384/512px를 유지했다. 서로 다른 크기의 소재를 같은 크기로 강제 확대하지 않았다. 큰 보드는 뷰어에서 축소될 수 있으므로, 이탈·판단 대상 47역할은 1600px 비교 보드와 동일한 128px 중앙 영역의 2배 NEAREST 확대를 추가했다. 확대 그림은 아트 수정본이 아니다.

모든 프레임의 정적 마감과 순서상 형상 변화는 확인했다. 실시간 재생의 체감 리듬, 실제 게임 배율·카메라·텍스처 필터·배경에서의 선명도 및 엔진 이동/레이어 합성은 **NOT_CHECKED**다. 명세의 scale이나 표시 크기 문구만으로 실제 게임에서 보았다고 기록하지 않는다. AREA00에는 독립된 PROJECTILE/REFERENCE 납품 역할이 없어 이 역할의 마감은 유사 소재 및 다른 Area의 같은 역할로 보완하고, AREA00 CAST 동작을 그대로 요구하지 않는다.

## 판정 운영

`CONSISTENT_WITH_REFERENCE`는 확인한 범위에서 명백한 스타일 이탈이 없다는 의미다. 사용자 승인·명세 통과·파일 통과·런타임 성공을 대신하지 않는다. `STYLE_OUTLIER`는 특정 마감 차이의 증거가 있는 수정 후보이고 자동 재생성 지시가 아니다. 정상적 소재/역할 단순화와의 경계가 불명확한 경우 `NEEDS_USER_REVIEW`로 남긴다.

기존 ART_REVIEW의 설정 판정은 보존하고, 스타일 필드는 이번 `CROSS_AREA_STYLE_REVIEW.csv`가 대체한다. AREA11 왕관 PROJECTILE의 기존 명세 위반 및 투명도 기술 보류는 별도로 유지한다. 킹 블록퍼스 CAST와 장난감 목마 CAST의 철회된 본체 위반 판정은 복원하지 않는다.
