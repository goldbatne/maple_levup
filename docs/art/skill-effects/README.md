# 몬스터 스킬 시전 이펙트 원본 (T21-1 · T32-3 · T37-3)

몬스터 스킬 **16종**의 **시전 이펙트**를 직접 그렸다. 아이콘(`../skill-icons/`)과
같은 방식이고, 다른 점은 **월드에 뜨는 그림**이라는 것뿐이다.

## 왜 한 장짜리 그림인가

`asset_create_account_resource_storage_item`이 받는 category가
**sprite / audioclip / avataritem뿐이라 animationclip은 올릴 길이 없다.**
그래서 `_EffectService:PlayEffectAttached`(클립 재생)를 못 쓴다.

대신 **한 장을 띄워 놓고 `Combat/SkillCastEffect.mlua`가 움직인다** —
커지고, 옅어지고, 돌고, 흐른다. 여러 장을 올려 프레임을 갈아끼우는 길도 있지만
(SpriteRUID 교체는 T11-1에서 쓴 방법) 4종 × 5장 = 20장을 올려야 하고 그림마다
프레임 수를 따로 관리해야 한다. 한 장 + 움직임이 싸고, 고칠 때도 한 장만 다시 올린다.

## 스타일 (`SkillTable.effect_style`)

| style | 스킬 | 움직임 |
|---|---|---|
| `burst` | 몸통 박치기 · 도끼 휘두르기 · 뼈 무덤 · 대지 가르기 · **끈적한 몸통 · 물방울 터뜨리기 · 어둠의 손아귀** | 확 커지며 조금 돈다 |
| `ring` | 푸른 껍질 · 강철 가죽 · **단단한 밑동** | 천천히 커진다 (안 돈다 — 돌면 고리가 어지럽다) |
| `cloud` | 포자 살포 · 어둠의 뿌리 · 화염 돌풍 · **요정의 인분** | 부풀며 위로 떠오른다 |
| `pierce` | 뿔 들이받기 · 저돌 맹진 | 앞으로 나가며 길어진다 |

**T32-3에서도 T37-3에서도 스타일을 새로 만들지 않았다.** 넷이 움직임을 충분히 덮고,
스타일을 늘리면 `SkillCastEffect.Apply`에 분기가 하나씩 붙는다 — 같은 움직임에
**다른 그림**을 물리는 편이 싸다.

## ⚠⚠ 같은 스타일을 쓰면 **실루엣**을 갈라야 한다 (T37-3)

burst가 이미 넷인데 다섯째를 또 **8방향 방사형**으로 그렸더니 슬라임·물방울·손아귀가
서로도, 기존 뼈 무덤과도 **색만 다른 같은 그림**이 됐다 (실측). 고친 방법:

| 스킬 | 처음 (틀렸다) | 고친 것 |
|---|---|---|
| 끈적한 몸통 | 8방향 팔 → **성게** | 좌우가 안 맞는 덩어리 + 흘러내리는 가닥 넷 |
| 물방울 터뜨리기 | 8방향 팔 → **눈꽃** | 이어지지 않은 방울을 반지름·크기 제각각으로 흩음 |
| 단단한 밑동 | 매끈한 동심 고리 → **강철 가죽과 같은 그림** | 고리를 열두 조각으로 잘라 **통나무 방책**으로 |
| 어둠의 손아귀 | 가는 팔 다섯 → **눈꽃** | 넷으로 줄여 굵게, 끝을 크게 꺾어 **갈고리**로 |

⚠ **덩어리를 겹칠 때는 테두리를 전부 먼저 깔고 본체를 전부 나중에 칠한다.**
덩어리마다 테두리→본체를 짝으로 그리면 뒤 것의 테두리가 앞 것 위에 그어져
**한 덩어리가 아니라 금이 간 것처럼** 보인다 (실측 — `SLIME_FX`의 `shape()` 참조).

`effect_style`이 **비어 있으면** `effect_ruid`는 원작 애니메이션 클립이고
`_EffectService`가 그대로 재생한다(히어로 5종). 채워져 있으면 우리 스프라이트다.
⚠ **칸을 나눈 이유**: 한 칸에 섞으면 런타임에 클립인지 그림인지 알 방법이 없고,
클립 자리에 그림을 넣으면 **에러 없이 안 뜬다.**

## ⚠ 실측으로 배운 것 셋

1. **그리기 순서.** `OrderInLayer` 6으로는 **캐릭터 뒤에 깔린다.** 500으로 올렸다.
2. **크기.** 96px = 1 월드 유닛이라 배율 1.0이면 사람만 하다. 캐릭터(약 1.4 유닛)보다
   커야 연출로 읽힌다 — 지금은 최대 2.7까지 커진다.
3. **투명도는 끝에서만 뺀다.** 처음부터 `1 - t`로 옅어지게 했더니 0.4초짜리 연출이
   뜨자마자 배경에 묻혀 "번쩍했나?" 수준이 됐다. 지금은 t가 0.5~0.65를 넘어서야 빠진다.

그리고 **이펙트는 아이콘과 색을 똑같이 두면 안 될 때가 있다.** 포자 구름을 아이콘과
같은 초록으로 뒀더니 **잔디 위에서 묻혔다.** 이펙트는 아무 배경 위에나 뜨므로
색조가 아니라 **명도 대비**로 버텨야 한다 — 테두리를 거의 검게, 속을 거의 흰 노랑으로 벌렸다.

### 이건 눈으로만 보면 놓친다 — 재라 (T37-3)

T37-3에서 5종을 그려 놓고 화면으로 봤을 때 **"보인다"고 판단했는데, 재 보니 세 종이
배경과 명도차 10~17이었다.** 테두리(차 125)만으로 버티고 있었던 것이고, 그림의 몸통
자체는 잔디에 묻혀 있었다.

| 스킬 | 주된 색 | 고치기 전 잔디차 | 고친 뒤 |
|---|---|---|---|
| 끈적한 몸통 | `#6cc22e` → `#2e7a12` | **10.6** | 56.1 |
| 물방울 터뜨리기 | `#2aa8d8` → `#79dcf7` | **9.8** (흙 12.9) | 46.4 (흙 69.2) |
| 요정의 인분 | `#ff8fd0` → `#ffb8de` | **17.0** | 47.4 |

기준은 **고쳐진 뒤의 포자 살포**다 — 주된 색 `#b8dc4e`가 잔디차 47.6 / 흙차 70.4.
**면적 12%가 넘는 색은 두 배경 모두에 대해 명도차 30 이상**이어야 한다.
게임 화면에서 뽑은 배경색: 잔디 `(132,174,27)` lum 154.5 / 흙 `(168,128,62)` lum 131.7.

⚠ **그림만 고치고 싶으면 `asset_update_resource_storage_data`를 쓴다** — RUID가
유지되므로 `SkillTable`을 안 고쳐도 되고 pivot·filter_mode 같은 속성도 남는다 (실측).

## 고치는 방법

```bash
node docs/art/skill-effects/draw-effects.cjs
python docs/art/skill-effects/rasterize.py docs/art/skill-effects/fx-spore-cloud.svg out.png 2
```

48×48 격자를 2배로 뽑아 96×96이 된다. 아이콘과 달리 화면에서 확대·축소되므로
격자가 정확히 맞아떨어질 필요는 없다.

**이미 올린 그림만 갈고 싶으면** `asset_update_resource_storage_data`를 쓴다 —
RUID가 유지되므로 `SkillTable`을 안 고쳐도 된다.

> ⚠ `asset_update_resource_storage_info`(메타데이터)는 **생략한 필드를 지운다.**
> name·description·subcategory·properties를 항상 같이 넘길 것.

### ⚠ 소리는 새로 안 찾았다 (T32-3)

페리온 7종의 `sfx_ruid`는 **이미 쓰이던 소리를 성격이 같은 것끼리 물려** 썼다.
이유는 하나다 — **소리는 들어볼 수가 없다.** 스프라이트는 그려서 눈으로 보고 고쳤지만
오디오는 검색 결과에 이름도 안 붙고(RUID만 온다) 재생해 볼 방법도 없다.
T19-2가 쓴 "아이콘 RUID로 원본 팩을 역추적한다"도 **직접 그린 아이콘에는 안 통한다** —
역추적할 원본 팩이 없다. 검증 못 한 RUID를 새로 넣느니 대표가 플레이로 확인한
소리를 재사용하는 편이 안전하다. **바꾸고 싶으면 CSV 한 칸이다.**

| 스킬 | 빌려온 소리 |
|---|---|
| 도끼 휘두르기 | 슬래시 블러스트 |
| 어둠의 뿌리 | 포자 살포(포이즌 미스트) |
| 저돌 맹진 | 몸통 박치기(돌진) |
| 강철 가죽 | 푸른 껍질(로얄 가드) |
| 뼈 무덤 | 브랜디쉬 |
| 화염 돌풍 | 레이징 블로우 |
| 대지 가르기 | 바위 던지기 |

**엘리니아 5종도 같다** (T37-3). 성격이 같은 것끼리 물렸고, 실드만 기존 둘과 공유한다:

| 스킬 | 빌려온 소리 | 왜 |
|---|---|---|
| 끈적한 몸통 | 몸통 박치기(돌진) | 몸으로 부딪힌다 |
| 단단한 밑동 | 푸른 껍질(로얄 가드) | 실드는 이미 둘이 공유 |
| 물방울 터뜨리기 | 바위 던지기 | 터지는 충격 |
| 요정의 인분 | 포자 살포(포이즌 미스트) | 떠도는 가루 구름 — cloud 스타일도 같다 |
| 어둠의 손아귀 | 레이징 블로우 | 보스라 가진 것 중 가장 무거운 소리 |

**바위 던지기는 시전 이펙트가 없다** — 날아가는 바위가 곧 연출이다 (T19-4).
