### AREA_03 · 버블링 · 물방울 마력 — 유지 가능

공식 비교: 워터실드; 버블 스타 / 버블 스타 강화

### AREA_03 · 페어리 · 요정의 마법가루 — 보정 권장
별가루/날개빛/나선 전개는 적합. 8프레임 모두 캔버스 끝에 alpha=1 잔류가 있음. 주요 형상 절단은 아니며 원화 재제작 없이 극미약 배경 잔류 정리 권장.

공식 비교: 정기 뿌리기 / 정기 뿌리기 강화; 미스트랄 스프링

### AREA_03 · 파우스트 · 저주의 인형 — 유지 가능
실로 묶인 인형 표식·자주색 침·충격광이 함께 읽힌다. 커스 마크/포이즌 니들의 날카로운 타격 대비를 모티브 복제 없이 반영. 파우스트 본체 직접 삽입 없음.

공식 비교: 커스 마크; [처형] 포이즌 니들

### AREA_04 · 옥토퍼스 · 먹물 폭발 — 유지 가능
먹물의 어두운 몸통·반사광·분리 방울이 확인된다. 꽃잎형 방사 얼룩은 INPUT 자체 지시이며 불필요한 취향 수정 대상으로 보지 않음.

공식 비교: 포이즌 미스트; 분출 : 너울이는 강 VI

### AREA_04 · 스티지 · 밤의 감각 — 유지 가능
얇은 야간 파문과 붉은 감지점이 ICON에서 구분된다. 감각 패시브의 추상 표식으로 타당.

공식 비교: 소울 레조넌스 / 소울 레조넌스 강화; 엔드리스 다크니스

### AREA_04 · 주니어 레이스 · 망령 충격 — 수정 필요
F00~F03 하단 형상이 같은 수평선에서 끊긴다. F04~F07 상단에 수평으로 잘린 독립 고리 조각이 남는다. 실제 ZIP PNG에서도 확인. 분할 경계 오류 의심이나 생성 시트/분할 기록 원인 추적은 이번에 미실시. 원본 재추출 우선 검토.

공식 비교: 워터실드; 커스 마크

### AREA_04 · 레이스 · 원혼의 기운 — 유지 가능
휘어진 혼령 띠·내부 불씨와 반투명 농도 변화가 읽힌다. 청록색 혼령 소재를 보존하며 ICON-only로 적합.

공식 비교: 엔드리스 다크니스; 워터실드

### AREA_04 · 셰이드 · 심연의 장막 — 유지 가능
중앙이 어둡고 가장자리만 보라빛인 장막이 성장 후 소멸한다. 빛을 삼키는 명세에 맞으므로 다른 공격처럼 중앙 흰 코어를 강제하지 않음. ICON 초승달 역시 명세에 명시됨.

공식 비교: 옵시디언 배리어 / 옵시디언 배리어 강화; 엔드리스 다크니스

### AREA_05 · 리본 돼지 · 리본 돌진 — 유지 가능
매듭→전방 리본 궤적→타격→분해가 구별된다. 분홍 천의 명암 면과 밝은 충돌광이 나뉘며 포스터형 고정 구성에 머물지 않음.

공식 비교: 스크류 펀치 / 스크류 펀치 강화; 소울 시커 VI

푸른 리본 매듭·조임 고리와 단정한 반사광으로 패시브를 식별할 수 있음. 몬스터의 리본색/소재와 연결됨.

공식 비교: 로얄 가드 VI; 소울 시커 VI

### AREA_05 · 불가사리 · 별가시 회전 — 유지 가능

### AREA_05 · 쿨 젤리피쉬 · 차가운 젤리 — 보정 권장
젤리 방울은 적합하지만 ICON의 서리 특성이 약해 보통 물방울과 구분이 약함. 작은 서리 면/차가운 가장자리만 보강 권장. 해파리 본체 삽입이나 전면 재생성은 불필요.

공식 비교: 워터실드; 블리자드 VI

### AREA_05 · 킹크랑 · 왕게의 집게 파도 — 보정 권장
갑각 면·파도 코어·분해는 완성도가 있다. 다만 F02~F07이 집게 닫힘보다 대칭 구도 확대와 파도 성장으로 읽혀 명세의 닫히는 타격을 더 명확히 할 필요가 있음. 붉은 집게는 INPUT 지정색이며 UUID 몬스터의 청색 갑각과 다른 점은 명세 재판단 항목.

공식 비교: 분출 : 너울이는 강 VI; 스크류 펀치 / 스크류 펀치 강화
