## 2. 단일 채팅의 병렬 작업 방식

다섯 Area를 별도 작업선 `AREA_01`, `AREA_02`, `AREA_03`, `AREA_04`, `AREA_05`로 초기화하고 가능한 실행 단계는 동시에 진행한다.

- 다섯 INPUT ZIP의 해시 계산, 압축 해제, 명세 읽기와 참조 이미지 확인은 병렬로 수행한다.
- 각 Area의 첫 필수 VFX 앵커 생성과 검증도 서로 독립적으로 진행한다.
- 이미지 생성 도구가 실제로 동시 호출을 지원하지 않으면 호출 자체는 사용 가능한 순서로 처리하되, 다섯 작업선의 상태를 독립 유지하고 한 Area만 끝낸 뒤 다음 Area를 시작하는 직렬 배치로 축소하지 않는다.
- 한 Area가 재생성·수정 중이어도 다른 Area에서 독립적으로 가능한 제작·검증·패키징은 계속한다.
- 사용자에게 몬스터별 또는 Area별 중간 승인을 요구하지 않는다.
- 이 단일 채팅 안에서 다섯 Area의 상태와 결과를 끝까지 관리한다.

각 Area 작업선은 자신의 INPUT 안에 있는 자료만 사용한다. 다른 Area의 MONSTER_IMAGE, prepared board, 생성 source, 실패본, VFX, ICON을 참조에 섞지 않는다. 공통 AREA 00 마감 자료는 각 INPUT에 포함된 지정 보드만 사용한다.

## 4. 생성 및 품질 게이트

각 Area는 자신의 Work Local 프롬프트와 `CHATGPT_WORK_LOCAL_ART_RULES.md`를 전부 적용한다.

- 원화 생성·편집에는 `$imagegen`을 실제로 사용한다.
- 각 스킬 호출에 해당 MONSTER_IMAGE, OFFICIAL_VFX_BOARD, AREA00_FINISH_BOARD를 실제 reference image input으로 전달하고 경로·SHA-256을 기록한다.
- 공식 VFX 보드의 게임 자산 렌더링 문법을 우선하고 AREA 00 보드는 마감·알파·가독성 기준으로 사용한다.
- 포스터, 키비주얼, 모바일 UI 엠블럼, 과한 플라스틱 스티커 형태는 아트 FAIL이다.
- 검은 점·대시·색 잔류·체커보드·흰/검정/회색 매트·인접 셀 조각은 오염 FAIL이다.
- 준비→성장→절정→해체→fade는 같은 피봇과 축에서 실제 형상 변화로 이어져야 한다.
- 생성자 자체 PASS 문구만 믿지 말고 최종 PNG와 공식 보드를 다시 열어 독립 판정한다.

각 Area의 앵커가 FAIL이면 그 Area의 나머지 스킬만 중지하고 실패 원인에 맞춰 앵커를 다시 만든다. 해당 실패 때문에 다른 네 Area 작업선을 중지하지 않는다. 실패 이미지를 어느 Area에서도 positive reference로 사용하지 않는다.

## 5. 상태 저장과 재개

각 스킬 완료 시 해당 Area의 `WORK_STATE.json`을 갱신한다. 배치 상태 파일 `BATCH_WORK_STATE.json`에는 Area별로 다음을 기록한다.

- `area_id`
- `state`: `NOT_STARTED / PREPARING / ANCHOR / GENERATING / VALIDATING / PASS / BLOCKED`
- 현재 skill_id
- 완료 스킬 수, VFX 수, ICON 수
- 마지막 성공 파일과 SHA-256
- 실패 원인과 재개 지점
- 최종 ZIP 경로와 SHA-256

사용량 제한이나 세션 중단이 발생하면 기존 PASS 결과를 다시 만들지 않고 각 Area의 마지막 재개 지점부터 계속한다.

## 6. Area별 패키징

한 Area의 모든 필수 자산이 파일 게이트와 아트 게이트를 모두 통과했을 때만 해당 Area의 정상 OUTPUT ZIP을 만든다.

- `AREA_01_IMAGES_OUTPUT.zip`
- `AREA_02_IMAGES_OUTPUT.zip`
- `AREA_03_IMAGES_OUTPUT.zip`
- `AREA_04_IMAGES_OUTPUT.zip`
- `AREA_05_IMAGES_OUTPUT.zip`

각 ZIP에는 해당 Area의 최종 VFX, ICON, Preview, labeled Preview, contact Preview, animation viewer, manifest, validation, reference 기록, work state와 result info만 넣는다. Area들을 한 ZIP에 합치지 않는다.

한 Area가 FAIL/BLOCKED이면 그 Area의 정상 이름 OUTPUT ZIP을 만들지 않는다. 다른 Area의 PASS ZIP은 그대로 완성할 수 있다.

## 7. 종료 조건

다섯 Area가 각각 PASS 또는 실제 BLOCKED 상태로 정리될 때까지 이 단일 채팅에서 작업한다. AREA 06 이후를 자동 시작하지 않는다.

최종 응답에는 다음만 간단히 보고한다.

- AREA 01~05 각각의 앵커 PASS/FAIL
- Area별 최종 상태와 완료 VFX/ICON 수
- Area별 전체 Preview 절대 경로
- 생성된 Area별 OUTPUT ZIP 절대 경로와 SHA-256
- BLOCKED Area가 있으면 그 원인과 정확한 재개 지점
