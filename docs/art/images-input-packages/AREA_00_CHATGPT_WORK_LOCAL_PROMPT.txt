[실제 이미지 생성 규칙]

- Python, Pillow, SVG, Canvas 또는 단순 도형으로 VFX/ICON 원화를 그리지 않는다. 이러한 도구는 생성 결과의 분리·리사이즈·알파 검사·Preview 합성·문서·ZIP 제작에만 사용한다.
- 기존 실패본이나 기존 AREA 01~20 OUTPUT은 참조하지 않는다.
- 하나의 생성 작업에는 하나의 monster_id와 하나의 skill_id만 포함한다.
- 여러 몬스터나 여러 스킬을 한 장의 Area 콘셉트 시트로 만들지 않는다.
- 이미지 생성·편집이 필요한 단계에서는 ChatGPT Work의 `$imagegen`을 실제로 호출한다.
- 생성 기록의 도구명은 `native image generation/editing — version/model unverified`로 쓴다. 세부 모델명을 추측하지 않는다.

각 VFX 생성 호출에는 다음 세 파일을 실제 reference image input으로 전달한다.

1. 해당 몬스터의 원본 `MONSTER_IMAGE.png`
2. 해당 skill_id의 `*_OFFICIAL_VFX_BOARD.png`
3. 해당 skill_id의 `*_AREA00_FINISH_BOARD.png`

경로를 텍스트에 적거나 이미지를 화면에 열어 본 것만으로 참조 전달을 완료했다고 기록하지 않는다. 세 파일을 `$imagegen` 호출의 실제 이미지 입력으로 연결하고, 호출 기록에 각 절대 경로와 SHA-256을 남긴다.

- MONSTER_IMAGE에서는 몬스터의 색·재질·부위 모티브만 가져온다. 몬스터 몸·얼굴·캐릭터를 VFX나 ICON에 넣지 않는다.
- OFFICIAL_VFX_BOARD에서는 메이플스토리 계열 게임 자산의 다층 명암, 중간톤 분리, 밝은 코어, 정돈된 파편, 반투명 가장자리와 프레임 진행 문법을 참고한다. 공식 스킬의 고유 실루엣·캐릭터·무기·문양을 복제하지 않는다.
- AREA00_FINISH_BOARD에서는 작은 크기에서 읽히는 실루엣, 깔끔한 알파, 재질과 발광의 마감 수준을 참고한다. 다른 스킬의 모양·색·효과를 대상 스킬에 복사하지 않는다.
- 최종 자산에는 텍스트, 번호, 셀 라벨, UI 패널, 체커보드, 불투명 사각 배경, 다른 스킬 조각을 넣지 않는다.

[첫 스킬 앵커 게이트]

먼저 `001 / m_snail / s_mon_snail_dew_trail`의 VFX 8프레임과 ICON 1개만 제작한다. 사용자 중간 승인을 요구하지 말고 다음 항목을 실제 최종 PNG로 자체 검증한다.

- INPUT의 몬스터·스킬명·역할·효과·방향·프레임 수와 일치
- 세 참조 파일이 실제 `$imagegen` 입력으로 전달됨
- 어두운 유색 외곽·분명한 중간톤·제한된 밝은 코어·입체적 재질·깔끔한 반투명 알파를 갖춤
- 준비→성장→절정→해체→fade가 프레임별 실제 형상 변화로 연결됨
- 같은 256×256 canvas, 기준축, 중심축과 공통 스케일을 유지함
- 포스터·키비주얼·한 장짜리 일러스트가 아니라 frame-separated 게임 VFX로 읽힘
- ICON이 VFX의 색·재질·핵심 모티브를 공유하고 64px에서도 읽힘
- 몬스터 본체·얼굴·텍스트·번호·UI·다른 소재가 없음

앵커가 실패하면 나머지 네 스킬을 생성하지 않는다. 실패를 `shape/material/motion/alpha/layout/contamination/reference`로 분류하고, 같은 요청을 반복하지 말고 실패 원인에 맞게 참조 선택·프롬프트·생성 방식을 바꾼 뒤 앵커만 다시 제작한다. 실패 이미지는 positive reference로 사용하지 않는다.

앵커가 통과하면 외부 제작 프롬프트의 순서대로 나머지 네 스킬을 한 스킬씩 제작한다. 각 스킬의 VFX가 자체 품질 게이트를 통과한 후에만 해당 ICON을 만들고 다음 스킬로 진행한다. 각 스킬 완료 시 `WORK_STATE.json`을 저장해 중단 시 마지막 PASS 다음부터 재개할 수 있게 한다.

최종 ZIP은 결과 실행 폴더 안에 저장한다. ZIP 생성 후 CRC, 엔트리 목록, SHA-256, PNG 수량, 각 PNG의 256×256 RGBA와 실제 alpha를 다시 검사한다. 게임 실행 검증은 수행하지 않고 `RUNTIME=NOT_CHECKED`로 기록한다.

하나라도 미완료이거나 아트 품질 게이트가 실패하면 정상 이름의 OUTPUT ZIP을 만들지 않는다. 보고서만 든 ZIP이나 실패 이미지 한 장짜리 ZIP으로 완료를 대신하지 않는다. 이 경우 마지막 작업 상태와 실패 증빙을 결과 폴더에 보존하고 미완료 항목을 명확히 보고한다.
