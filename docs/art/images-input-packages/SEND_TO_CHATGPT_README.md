# 보내는 방법

해당 Area의 AREA_XX_IMAGES_INPUT.zip과 AREA_XX_CHATGPT_PRODUCTION_PROMPT.txt 두 파일을 함께 첨부하고 **첨부한 프롬프트대로 실행해줘**라고 보내세요.

공식 스킬의 실제 연속 PNG/GIF·ICON과 AREA00 마감 PNG가 각 ZIP에 들어 있습니다. 공통 대용량 ZIP은 보내지 않습니다. AREA00부터 새로 제작하며 기존 OUTPUT은 덮어쓰지 않습니다. 현재 운영 목록에는 AREA06이 없습니다.

제작은 첫 필수 VFX 스킬로 참조 입력→원화→프레임 분리→알파·동작 검증→ICON 파이프라인을 먼저 통과시킨 후, manifest 순서대로 한 스킬씩 진행합니다. 여러 몬스터를 한 장의 Area 전체 콘셉트 시트로 생성하거나 실패 시안·보고서만 든 ZIP을 최종 OUTPUT으로 제출하면 안 됩니다.

ZIP 내부 reference_resource_design/REFERENCE_VIEWER.html을 풀어서 열면 스킬별 연결을 확인할 수 있습니다.
