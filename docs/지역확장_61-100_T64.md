# T64 지역 확장 — Lv61~100

상태: 구현·Maker 런타임 검증 완료

## 목표

기존 8방 지역 규격을 유지하면서 `area_07`부터 `area_10`까지 네 지역을 추가한다. 모든 지역은 4종의 일반 몬스터와 1종의 지역 보스, 8개의 분기형 방, 전용 타일 4종, 포획 스킬과 장비 드랍을 가진다.

## 지역·몬스터 확정안

| 지역 | 레벨 | 일반 몬스터 | 보스 | 교차 검증 기준 |
|---|---:|---|---|---|
| `area_07` 슬리피우드 | 61~70 | 좀비버섯, 카파 드레이크, 드레이크, 와일드카고 | 타우로마시스 | 슬리피우드의 늪·개미굴·드레이크 동굴·저주받은 신전 계열 |
| `area_08` 오르비스 | 71~80 | 스타픽시, 주니어 샐리온, 루나픽시, 러스터픽시 | 엘리쟈 | 오르비스 구름공원과 픽시·샐리온 계열 |
| `area_09` 엘나스 산맥 | 81~90 | 주니어 예티, 다크 주니어 예티, 헥터, 화이트팽 | 설산의 마녀 | 엘나스 설원 몬스터와 지역 필드 보스 |
| `area_10` 아쿠아로드 | 91~100 | 버블피쉬, 마스크피쉬, 스퀴드, 샤크 | 피아누스 | 아쿠아로드 연안에서 심해로 내려가 피아누스 동굴에 도달하는 흐름 |

지역 소속은 MapleStory World Archive의 지역별 몬스터 목록과 MSW Resource Storage의 공식 몬스터 팩을 함께 확인한다. 원작 레벨은 지역 정합성 참고값으로만 쓰고, 실제 수치는 이 프로젝트의 10레벨 구간 공식에 맞춰 재배치한다.

## 공통 방 구조

```text
                 r_xxa 보상 막다른 방
                      ↑N
r_xx1 ─E→ r_xx2 ─E→ r_xx3 ─E→ r_xx4 ─E→ r_xx5 보스
              ↓S               ↑N
             r_xx6 ─E→ r_xx7 ──┘
```

- 진입방은 마을 복귀와 진행 포탈을 명확히 분리한다.
- 보상 막다른 방은 직전 지역 보스 포획 스킬을 요구한다.
- 보스 직전 방은 누적 스탯 게이트를 사용한다: 315 → 365 → 415 → 465.
- 보스는 HP ×10, DEF ×1, ATK ×1.5, 제한시간 300초, 전용 장비 확정 드랍 규격을 유지한다.
- 물·절벽·심연 타일은 이동 불가로 처리하고 다리·통로만 걸을 수 있게 한다.

## 단계

1. 데이터: 지역·랜드마크·방·몬스터·스킬·아이템 20종을 추가한다.
2. 모델: 공식 MSW 몬스터 팩의 stand/move/hit/die/attack RUID로 20개 모델을 만든다.
3. 맵: 지역별 전용 타일 4종과 8방씩 총 32개 맵을 Builder로 생성한다.
4. 통합: 월드맵·가방·스킬 UI가 50종까지 표시되도록 용량을 확장한다.
5. 검증: 32맵 448칸, 포탈 역연결, 충돌, 스폰, 보스 HUD·초기화·확정 드랍을 정적 검사와 Maker Play로 확인한다.

## 완료 조건

- `area_07`~`area_10` 각 8방, 전체 32방이 등록된다.
- 신규 몬스터 20종이 모두 공식 MSW 몬스터 팩과 이름·외형이 일치한다.
- 각 몬스터의 포획 스킬과 장비 보상이 데이터에서 단일하게 연결된다.
- 모든 맵은 RectTile `TileMapMode=1`, 448타일, 깨진 양방향 연결 0개다.
- 위험 타일은 통과 불가이고 포탈·스폰 지점은 걸을 수 있는 타일 위에 있다.
- Maker 빌드 오류 0, 대표방과 네 보스방의 런타임 로그·화면 확인을 남긴다.

## 정적 검증 기록

- 방 연결 상호 일치, 위험 타일 경계 컴포넌트 일치
- 공식 MSW 몬스터 모델 20종: 각 13컴포넌트·29값, 모델 검사 오류 0
- 신규 포획 스킬 20종과 장비 20종의 단일 연결 확인
- 전체 콘텐츠: 포획 몬스터 50종, 몬스터 스킬 50종, 일반 장비 50종, 보스방 12개
- 장착 스킬 스크롤 격자 50칸 확장 및 UIBuilder 검사 통과
