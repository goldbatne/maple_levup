# 검증 가이드

> 갱신: 2026-09-07

## 검증 층

| 층 | 방법 | 증명하는 것 | 증명하지 못하는 것 |
|---|---|---|---|
| 정적 구조 | Node 검증 스크립트 | CSV 참조, 파일 존재, 맵 연결, UI 바인딩, 상수 | Maker 등록, 실제 화면·입력 |
| Maker 빌드 | Refresh 후 build logs | mLua 등록·컴파일과 엔트리 반영 | 플레이 감각, 클릭 결과 |
| Maker Play | play + 입력 + normal logs + screenshot | 실제 진입, 스폰, 전투, UI, 충돌 | 저장 재접속 회귀는 별도 시나리오 필요 |

정적 검사 통과만으로 “런타임 확인 완료”라고 쓰지 않는다.

## 기본 명령

```text
node docs/tools/verify-content-coverage.cjs
node docs/tools/verify-knowledge-base.cjs
```

T58 동안은 다음도 실행한다.

```text
node docs/tools/verify-area00.cjs
```

`verify-area00.cjs`가 SectorConfig 누락을 보고하면 파일 구조가 맞아도 Maker Refresh/저장 전 상태다.

## Maker 체크 순서

1. 작업 전 Play 중이면 Stop한다.
2. Refresh하고 Maker 저장을 기다린다.
3. build log에서 오류와 신규 파일 등록 실패를 확인한다.
4. Play를 시작하고 normal log의 주요 초기화 체크포인트를 확인한다.
5. 화면 좌표는 screenshot으로 확인한 뒤 실제 mouse/keyboard input을 호출한다.
6. 지역 이동이 있는 검증은 시작 맵과 현재 맵을 로그로 확인한다.
7. 종료 후 다시 정적 검증을 실행해 Maker 저장이 데이터를 지우지 않았는지 확인한다.

## T58 완료 기준

- SectorConfig에 `map001`, `map002`, `map003`, `map00a`, `map004`, `map005`, `map006`, `map007` 등록
- 빌드 오류 0
- `area_00` 기본 해금과 Lv10~50 연속 지역 해금
- 8방 포탈 왕복과 몬스터 스폰 정상
- 해안/모래/숲 화면과 통과 불가 지형 일치
- 마노 보스 HP바, 제한시간 초기화, 확정 아이템 드랍 정상
- 전체 콘텐츠 검증과 지식 검증 통과
