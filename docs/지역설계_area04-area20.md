# 지역 설계 — area_00 ~ area_20

> 기존 파일명은 링크 호환을 위해 유지한다. 갱신: 2026-09-07.

## 공통 규격

- RectTileMode 1, 1타일 100px 기준
- 지역당 기본 8방, 일반 몬스터 4종 + 보스 1종
- 진입방은 마을/이전 지역 복귀와 지역 진행 포탈을 명확히 분리
- 분기, 막다른 보상방, 우회 연결을 최소 하나 둔다
- 물·절벽 등 막힌 외형은 충돌도 막고, 갑판·다리·통로는 걸을 수 있게 만든다
- 맵 파일 재직렬화는 피하고 전용 MapBuilder/생성기와 줄 수·타일 수 검사를 사용한다
- 다음 지역은 해당 10레벨 대역 시작 시 해금한다

## 구현 체크리스트

1. 원작 지역과 어울리는 일반 몬스터 4종·보스 1종을 공식 자료로 확인한다.
2. 몬스터 레벨·HP·DEF·EXP, 드랍 스킬과 장비를 GameData에 추가한다.
3. 모델과 8맵을 공식 빌더 흐름으로 만든다.
4. 방 연결, 포탈, 스폰, 타일 448칸, 충돌과 미니맵을 정적으로 검사한다.
5. Maker Refresh/저장 후 빌드 로그를 확인한다.
6. 카메라 화면, 전 방 이동, 보스 HP바·제한시간·확정 드랍을 Play에서 검증한다.

과거의 상세 후보와 계산 과정은 `archive/legacy/지역설계_area00-area20_legacy.md`에 있다.
