# 게임 기획서 — 현행 설계 정본

> 파일명 `v0.3`은 기존 링크 호환을 위해 유지한다. 갱신: 2026-09-07.

## 한 문장

메이플스토리 월드를 탐험하며 몬스터의 스킬을 포획하고, 장비와 히든 전직 보상으로 성장해 Lv200까지 지역 보스를 돌파하는 싱글 플레이 RPG다.

## 핵심 경험

1. 서로 다른 경로와 지형을 가진 지역을 탐험한다.
2. 몬스터를 처치해 그 몬스터의 스킬을 얻는다.
3. 획득한 스킬과 장비를 조합해 더 강한 지역과 보스에 도전한다.
4. 히든 전직 보스를 반복 공략해 직업 주스탯을 추가로 성장시킨다.

지역은 일직선 복도가 아니라 분기, 막다른 보상방, 우회 연결과 랜드마크를 사용한다. 지형 자체가 지역의 정체성을 전달해야 하며 불필요한 장식 오브젝트에 의존하지 않는다.

## 전투 계약

- 플레이어 직접 공격과 포획한 몬스터 스킬이 전투의 중심이다.
- 직업 캐릭터의 고유 스킬은 드랍하지 않는다. 직업 능력까지 빼앗는다는 인상을 피하고 몬스터 포획 정체성을 지킨다.
- 같은 몬스터 스킬은 최대 5장까지 누적한다. 최대치 이후에는 중복 포획이 발생하지 않는다.
- 보스는 상단 HP바와 5분 제한시간을 사용한다. 재입장하면 새로운 보스전으로 HP와 시간이 초기화된다.
- 보스 아이템은 클리어 보상으로 확정 드랍한다.

## 성장 계약

- 레벨, 기본 스탯 배분, 장비, 포획 스킬, 전직 패시브를 별도 축으로 둔다.
- 일반 장비는 무기·방어구·장신구 슬롯에 장착한다.
- 전직 패시브는 인벤토리에 보유하면 적용된다. 히어로는 STR, 보우마스터는 DEX를 아이템 한 개당 +10, 최대 5개까지 얻는다.
- 표시용 스탯과 실제 전투 계산은 같은 최종 수치를 사용한다. 최종 4스탯은 소수값을 허용한다.

## 지역 계약

- 각 지역은 대체로 10레벨 대역, 8개 방, 일반 몬스터 4종과 보스 1종을 기본 단위로 삼는다.
- 해금 랜드마크는 다음 레벨 대역이 시작될 때 해당 지역을 연다.
- 마을 동쪽 문과 월드맵으로 해금된 지역에 진입한다.
- 물, 절벽 등 시각적으로 통과할 수 없어 보이는 지형은 실제 충돌도 일치시킨다.
- 카메라 화면에서 경계, 반복 무늬, 포탈 진입 지점과 이동 경로를 확인한다.

## UI 계약

- 전투 화면을 가리지 않는 것이 우선이다.
- 월드맵은 지역 선택과 함께 몬스터·획득 가능 아이템 정보를 제공한다.
- 스킬 화면은 몬스터 스킬만 보여준다.
- 가방은 장신구·방어구·무기·패시브를 분류하고 장비 더블클릭을 지원한다.
- 스탯 화면은 최종 STR/DEX/INT/LUK을 중심으로, 상세 패널은 파생 스탯과 선택한 주스탯의 영향 범위를 보여준다.

## 범위

현재 목표는 기존 동작을 유지하며 Lv200까지 지역을 확장하는 것이다. 멀티플레이, 거래, 재료 아이템 제작, 직업 스킬 포획은 현행 범위가 아니다.
