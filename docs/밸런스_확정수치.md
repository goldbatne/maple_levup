## 2. 공식

```
데미지        = 계수 × ATK² / (ATK + DEF)          [최소 1 보장, 반올림]
필요 EXP(Lv)  = 20 × 1.12^(Lv-1)
몬스터 HP(Lv) = 144 + 34.2 × (Lv-1)      ← 선형 (T28)
몬스터 DEF(Lv)=  80 + 19   × (Lv-1)      ← 선형 (T28)
몬스터 ATK(Lv)= 157 + 11.5 × (Lv-1)      ← 선형 (T28)
몬스터 EXP(Lv)=  5 × 1.10^(Lv-1)      ← EXP만 기하급수로 남는다

플레이어 물리공격력 = 10 + STR×5 + DEX×2 + LUK×2
플레이어 마법공격력 = 10 + INT×5
플레이어 방어력     = 10 + DEX×10
플레이어 최대 HP    = 1000 + STR×20
포획 확률     = 3% + LUK × 0.1%p                   (종별 40킬 천장)
```

- **자동 공격의 계수 스탯 = `max(물리, 마법)`** (2026-08-08 결정). 스킬은 각자의 `scaling_stat`을 따른다.
- `scaling_stat`은 이제 **스탯이 아니라 수치 이름**이다 — `ATK`=물리 공격력, `INT`=마법 공격력.
  **`LUK`은 폐기됐다**(T27-2) — LUK이 물리 공격력에 직접 기여하게 되어 근거가 사라졌다.
- **왜 몬스터가 선형인가**: T27에서 플레이어 스탯이 레벨에 선형(1P당 +5 고정)이 됐다.
  선형과 기하급수는 **딱 한 번만 교차**하므로, 옛 곡선에서는 교차점(Lv55 근처) 아래가
  전부 한 방이고 위가 전부 불가능이었다. base를 조절해도 교차점만 좌우로 움직인다.
- 크리티컬은 **꺼져 있다** — 시트에 확률·배율이 없어서 `CalcCritical`이 항상 `false`.
