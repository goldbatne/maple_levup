# 밸런스 확정 수치

> 갱신: 2026-09-07 · 사람용 요약. 실행 정본은 `RootDesk/MyDesk/GameData/GameBalance.csv`와 관련 계산 코드다.

## 핵심 상수

| 항목 | 값 | 의미 |
|---|---:|---|
| 레벨 상한 | 200 | 현재 성장 목표 |
| 레벨당 스탯 포인트 | 5 | 환생 보너스는 별도 |
| Lv1 필요 EXP | 60 | `exp_base` |
| 필요 EXP 공비 | 1.105 | `exp_ratio` |
| Lv1 몬스터 EXP | 5 | `monster_exp_base` |
| 몬스터 EXP 공비 | 1.10 | `monster_exp_ratio` |
| 스킬 기준 계수 | 1.2 | 기본 데미지 계수 |
| 몬스터 스킬 중복 상한 | 5 | 최대치면 포획 판정 생략 |
| 기본 포획률 | 3% | LUK 0 기준 |
| LUK 포획 보정 | 1당 +0.1%p | 확률에 정액 가산 |
| 포획 천장 | 종별 40킬 | 천장 시 확정 |
| 플레이어 피격 무적 | 1초 | 전투 생존 시간의 기준 |
| 보스 HP/DEF/ATK | ×10 / ×1 / ×1.5 | room_type=boss |
| 보스 EXP | ×3 | 재입장 반복 가능 |
| 보스 제한시간 | 300초 | 시간초과 시 보상 없이 퇴장 |

## 공식

코드의 반올림은 `math.floor(x + 0.5)`를 사용하며 몬스터 DEF는 소수 첫째 자리까지 유지한다.

```text
필요 EXP(Lv)   = round(60 × 1.105^(Lv-1))
몬스터 EXP(Lv) = round(5 × 1.10^(Lv-1))
몬스터 HP(Lv)  = round(144 + 34.2 × (Lv-1))
몬스터 DEF(Lv) = round1(80 + 19 × (Lv-1))
몬스터 ATK(Lv) = round(157 + 11.5 × (Lv-1))
데미지          = round(계수 × ATK² / (ATK + DEF)), 최소 1
```

개별 몬스터의 HP·DEF·EXP는 `MonsterTable.csv`가 우선하며 검증기가 위 곡선과의 일치 여부를 검사한다.

## 직업 패시브 보상

| 아이템 | 효과 | 유효 상한 |
|---|---|---:|
| 히어로의 검 | 보유 1개당 STR +10 | 5개, STR +50 |
| 보우마스터의 활 | 보유 1개당 DEX +10 | 5개, DEX +50 |

이는 장비 퍼센트 보너스가 아니라 인벤토리 보유 수량에 따른 고정 주스탯이다. 일반 장비의 기존 능력치는 별도 장비 계산을 따른다.
