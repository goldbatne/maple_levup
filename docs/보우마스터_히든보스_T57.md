# T57 보우마스터 히든 보스 작업 원장

엘리니아 `r_29`의 숨은 모험가를 통해 `r_job_02` 바람의 사격장으로 들어가 보우마스터와 싸운다. 히어로 시험의 공통 규칙(300초, 상단 보스바, 빈 방 리셋, 전용 보상 확정 드랍)을 재사용한다.

| 항목 | 소유자 | 상태 | 검증 증거 |
|---|---|---:|---|
| 입장 NPC와 이중 확인 | `HeroNpc` + `BowmasterNpc.model` | 완료 | Maker에서 `경고 표시` → `시험의 방으로 이동 요청` → `r_job_02` 이동 확인 |
| 전용 방과 귀환 | `mapjob02` + `BowmasterReturnPortal.model` | 완료 | 격파 후 `[ReturnPortal] 귀환 → r_29(map29)` 및 현재 맵 `map29` 확인 |
| 보스 스탯과 HUD | `RoomMonster` + `RoomSpawner` | 완료 | HP 11,360·DEF 631·ATK 736.5, 제한 300초, 상단 보스바 화면 확인 |
| 아바타와 활 사격 모션 | `Bowmaster.model` + `MonsterAttack.AvatarAttackAction=shoot1` | 완료 | 붉은 궁수 아바타 화면 및 `shoot1` 실행 로그 확인 |
| 3단계 스킬 선택 | `MonsterAttack` + `SkillTable` | 완료 | HP 100%/60%/20%에서 1/2/3단계 진입 확인 |
| 투사체·팬·플래터·피닉스·연사 | `MonsterAttack` + `SkillEffect` | 완료 | 5종 직접 시전, 3발 팬·4회 플래터·피닉스 반경 1.4·5회 연사 로그 확인 |
| DEX +10 패시브(최대 5) | `ItemTable` + `PlayerStats` | 완료 | 보유 1개당 DEX +10, 최대 +50이 ATK·DEF에 즉시 반영 |
| 최종/상세 스탯 UI | `StatPanel` + `StatGroup.ui` | 완료 | 일반 창은 최종 STR/DEX/INT/LUK만 표시하고, `상세 +`를 누르면 왼쪽에 ATK·마력·DEF·HP·공속·이속·포획률·드랍 보너스·히든 보스 패시브를 표시 |
| 확정 보상 | `ItemDrop` 공통 보스 규칙 | 완료 | 세 번 모두 확률 1.000 `[보스 전용 확정]` 및 자동 획득 확인 |
| 빌드·런타임 | Maker MCP | 완료 | refresh 성공, build 0건, 입장·전투·드랍·귀환 실측 완료 |

## 공식 대응

- 1차: 애로우 블로우
- 2차: 바람의 시
- 3차: 애로우 플래터, 피닉스
- 4차: 폭풍의 시

사용 RUID는 MSW 공식 스킬 리소스 팩과 아바타 아이템 검색 결과에서 가져왔다. 보우마스터 아바타는 레드 헌터·레드 아르미스·레드 힌켈 조합을 사용한다.

## 런타임 메모

- 재입장 시 보스가 HP 11,360으로 새로 생성되고 제한시간 300초가 다시 시작됐다.
- `BowmasterReturnPortal`의 `TriggerComponent.IsLegacy=false`를 Builder에 명시해 새 포탈 경고를 제거했다.
- 맵 전환 직후 `RoomBounds`가 타일맵을 한 번 못 찾은 뒤 정상 범위를 계산하는 기존 타이밍 경고와 `map29/Portal_S`의 기존 Legacy 경고는 이번 기능과 별개다.

## 스탯 창 후속 개편

- 일반 창의 네 능력치는 `분배 포인트 + 포획 컬렉션 포인트 + 히든 보스 장비 정액 보유 효과`를 합친 **최종 STR/DEX/INT/LUK**다.
- 보우마스터의 활은 보유 1개당 DEX +10, 최대 5개로 DEX +50을 제공한다.
- 일반 장비가 올리는 물리 공격력·마법 공격력·방어력 같은 파생 수치는 검은 헤더 왼쪽의 파란 `상세 +` 버튼으로 여는 창에 분리했다.
