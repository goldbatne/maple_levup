# 프로젝트 현황

> 기준: 2026-09-07 · 브랜치 작업 상태: T58 진행 중

## 한눈에 보기

- 장르: RectTile 기반 싱글 플레이 성장 RPG
- 핵심 루프: 사냥 → 몬스터 스킬 포획 → 장비·스탯 성장 → 지역/보스 도전
- 구현 지역: 6개(`area_00`, `area_01`, `area_03`, `area_02`, `area_04`, `area_05`)
- 기존 런타임 검증 완료 지역: 헤네시스 근교, 엘리니아, 페리온, 커닝시티, 노틸러스
- 신규 작성·런타임 미검증 지역: 메이플 아일랜드·리스항구(`area_00`)

## 현재 콘텐츠 정본

| 항목 | 현재 값 |
|---|---:|
| 포획 대상 몬스터 | 30종 |

| 일반 장비 | 30종 |
| 전직 패시브 보상 | 2종 |

보스방은 마노, 머쉬맘, 히어로, 보우마스터, 스텀피, 쉐이드, 파우스트, 주니어 발록이다. 보스 공통 규칙은 HP ×10, DEF ×1, ATK ×1.5, 제한시간 300초, 아이템 확정 드랍이다.

## 성장과 보상

- 동일 몬스터 스킬은 최대 5장이다. 최대치에서는 포획 판정을 건너뛴다.
- 직업 스킬은 포획하지 않으며 전직 보스의 전투 전용 능력으로만 사용한다.
- 히어로의 검은 보유 1개당 STR +10, 보우마스터의 활은 보유 1개당 DEX +10을 준다. 각각 최대 5개가 유효하다.
- 패시브 보상은 인벤토리 보유 효과이며 별도 장착을 요구하지 않는다.
- 일반 장비는 무기·방어구·장신구로 분류하고 더블클릭으로 장착/해제한다.
- 최종 STR/DEX/INT/LUK은 소수값을 유지하며 계산에도 같은 값을 사용한다.

## UI

- 상단 HUD의 스탯·가방·스킬 버튼은 우측 정렬이다.
- 획득 창은 제거했다. 월드맵 지역 버튼을 누르면 해당 지역의 몬스터와 획득 가능 보상을 팝업으로 본다.
- 스탯 창에는 최종 4스탯을 표시하고 파란 `상세` 버튼으로 좌측 상세 스탯 패널을 연다.
- 스킬 창은 몬스터 스킬 단일 분류다.
- 가방은 장신구·방어구·무기·패시브 분류를 제공한다.

## 검증 상태

`verify-content-coverage.cjs` 기준 콘텐츠·UI·보스·스킬·패시브 연결은 통과했다. `area_00`은 8맵, 맵당 448타일, 상호 연결, RectTileMode 1, 빨간 달팽이·마노 모델까지 정적 검사를 통과했다. 다만 SectorConfig에 8맵이 아직 등록되지 않아 Maker Refresh/저장과 실제 플레이 검증 전에는 완료가 아니다.
