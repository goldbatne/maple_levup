## 한눈에 보기

- 장르: RectTile 기반 싱글 플레이 성장 RPG
- 핵심 루프: 사냥 → 몬스터 스킬 포획 → 장비·스탯 성장 → 지역/보스 도전
- 구현 지역: 10개(`area_00`, `area_01`, `area_03`, `area_02`, `area_04`, `area_05`, `area_07`~`area_10`)
- 기존 런타임 검증 완료 지역: 헤네시스 근교, 엘리니아, 페리온, 커닝시티, 노틸러스
- 신규 작성·런타임 미검증 지역: 메이플 아일랜드·리스항구(`area_00`)

## 성장과 보상

- 동일 몬스터 스킬은 최대 5장이다. 최대치에서는 포획 판정을 건너뛴다.
- 직업 스킬은 포획하지 않으며 전직 보스의 전투 전용 능력으로만 사용한다.
- 히어로의 검은 보유 1개당 STR +10, 보우마스터의 활은 보유 1개당 DEX +10을 준다. 각각 최대 5개가 유효하다.
- 패시브 보상은 인벤토리 보유 효과이며 별도 장착을 요구하지 않는다.
- 일반 장비는 무기·방어구·장신구로 분류하고 더블클릭으로 장착/해제한다.
- 최종 STR/DEX/INT/LUK은 정수로 반올림하고 전투 계산에도 같은 값을 사용한다.

## UI

- 상단 HUD의 스탯·가방·스킬 버튼은 우측 정렬이다.
- 획득 창은 제거했다. 월드맵 지역 버튼을 누르면 해당 지역의 몬스터와 획득 가능 보상을 팝업으로 본다.
- 스탯 창에는 최종 4스탯을 표시하고 파란 `상세` 버튼으로 좌측 상세 스탯 패널을 연다.
- 스킬 창은 몬스터 스킬 단일 분류다.
- 가방은 장신구·방어구·무기·패시브 분류를 제공한다.

## 검증 상태

`verify-content-coverage.cjs` 기준 50몬스터·50포획 스킬·53아이템·12보스와 UI 연결은 통과했다. `area_07`~`area_10`은 32맵 전부 Maker에서 직접 열어 방별 스폰과 런타임 오류 0건을 확인했다. 네 보스는 HP ×10·300초 HUD가 열렸고, 타우로마시스 재입장 초기화와 피아누스 장비 확정 드랍도 확인했다. Build Console 오류는 0건이며 과거 권장값 경고만 남아 있다.
