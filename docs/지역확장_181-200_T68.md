## 범위

- `area_19` 미래의 문, Lv181~190, Lv180 해금
- `area_20` 황혼의 페리온, Lv191~200, Lv190 해금

## 장비와 UI

- 장비는 MSW Resource Storage의 실제 avataritem 이름·아이콘을 사용한다.
- 신규 분포는 방어구 4, 장신구 1, 무기 5다. 누적 방어구 48종으로 가방의 분류별 48칸 한도를 넘지 않는다.
- 몬스터 스킬 장착 창은 91칸에서 101칸으로 확장했다.

## 검증 기록

- `node docs/tools/verify-area19-area20.cjs`: 16방·10몬스터·10스킬·10장비, 맵당 448칸, 왕복 연결, 위험 타일 충돌 통과
- `node docs/tools/verify-content-coverage.cjs`: 전체 101몬스터·101포획 스킬·104아이템·22보스, 누락 RUID·장비·UI 셀 0
- `node docs/tools/verify-knowledge-base.cjs`: 20지역 순서와 문서 정본 통과
- Maker Refresh 뒤 신규 16맵을 전부 열어 등록을 확인했다. 대표 일반방 `map191`은 정식기사 C, `map201`은 변형된 다크 스텀프가 각각 정상 스폰했고 두 맵 모두 448칸으로 계산됐다.
- `map195` 시그너스는 **HP 66,080 / DEF 3,671 / ATK 3,496.5 / 300초**, `map205` 변형된 스텀피는 **HP 69,500 / DEF 3,861 / ATK 3,669 / 300초**로 실측했다.
- 시그너스 HP를 123까지 낮춘 뒤 방을 완전히 비우고 재입장하자 **66,080/66,080**으로 다시 스폰했다. 보스 전용 아이템 2종의 확정 드랍 배선은 정적 검증으로 확인했다.
- 빌드 오류는 0이다. 기존 `Mano.InputSpeed`, `Bowmaster.AvatarAttackPlayRate` 경고 2건만 남아 있다.
- 런타임 검증 중 저장방 자동전투로 변한 테스트 데이터는 **Lv122 / EXP 942,962 / 미분배 880 / `r_13a` / 모래난쟁이 스킬 1장·천장 31**로 저장 원복했다.
