# 몬스터 지역·보스·스킬·이펙트 감사 (T52)

- 감사일: 2026-08-30
- 범위: 현재 구현된 포획 대상 28종 + area_06~20의 보스 설계
- 정본: `MonsterTable.csv` / `RoomTable.csv` / `SkillTable.csv` / MSW 공식 몬스터 리소스 팩

## 판정 기준

1. **지역**: 방 이름과 몬스터가 같은 원작 지역·사건에서 왔는가.
2. **보스**: 고유 보스/필드 보스인가. 일반 몬스터 한 마리를 임의로 보스로 세우지 않았는가.
3. **스킬**: 몬스터의 몸·공격 모션·설정에서 바로 읽히는 행동인가.
4. **이펙트**: 공식 팩에 공격용 effect/ball/sound가 있으면 우선 사용한다. 없으면 기존 커스텀
   그림을 쓰되 실루엣이 행동과 맞아야 한다.
5. **패시브**: 보유 효과이므로 시전 이펙트·소리·투사체를 재생하지 않는다.

## 유지한 예외 — 노틸러스 주니어 발록

주니어 발록은 노틸러스 토착 몬스터는 아니지만 **배를 습격하는 사건의 보스**라서 유지한다.
방 이름을 `습격당한 노틸러스 갑판`으로 바꿔 예외의 이유를 화면에도 드러냈다. 이후 area_07
슬리피우드 `금지된 제단`에서는 원래 거처의 재전으로 쓴다. 같은 종을 무관하게 두 번 쓰는 것이
아니라 `노틸러스 침입 → 본거지 추적`의 두 장면이다.

## 자동 검증으로 고정한 규칙

- 포획 대상 28종 모두 `drop_skill_id`와 전용 드랍 아이템이 있어야 한다.
- key 게이트가 가리키는 스킬은 존재하고 `is_key_skill=true`여야 한다.
- 패시브에는 이펙트·스타일·소리·투사체·범위·지속·효과값이 남으면 안 된다.
- 액티브 몬스터 스킬은 시전 이펙트 또는 투사체 중 하나가 반드시 있어야 한다.
- 장착 창의 실제 셀 수와 `EquipPanel.cellCount`는 모두 28이어야 한다.

Maker Refresh 뒤 남은 실기 확인은 `r_05` 머쉬맘 스폰·공격 모션·포자 충격,
`r_045` 셰이드 보스·심연의 장막, `r_29`/`r_05a` 새 열쇠 통과·차단이다.
