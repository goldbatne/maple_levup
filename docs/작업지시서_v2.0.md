# 작업지시서 v2.0 — 보존용 진입점

이 파일의 과거 T0~T10 장문 지시서는 `archive/legacy/작업지시서_v2.0_T0-T10.md`로 옮겼다. 당시 실행 순서는 역사 자료이며 현재 에이전트의 기본 작업 목록이 아니다.

현재 작업은 다음 문서만 따른다.

1. `프로젝트_현황.md` — 검증 완료 상태
2. `인수인계_현재상태.md` — 미완료와 바로 다음 행동
3. 요청 영역의 설계 정본
4. `검증가이드.md` — 완료 판정

새 장문 작업 일지는 만들지 않는다. 작업 결과는 Git 커밋/PR에 남기고, 정본에는 최종 결정과 현재 상태만 반영한다.
