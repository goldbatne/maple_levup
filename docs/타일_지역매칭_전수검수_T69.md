# T69 지역 타일 지역성·가독성 전수 검수

> 기준: 2026-09-15 · 대상: `area_00`~`area_20` 실제 20지역(예약 결번 `area_06` 제외) · 이번 문서는 검수와 후속 작업 정의이며 타일·맵 원본은 아직 변경하지 않는다.

## 결론

- 지역별 타일 **소재와 색상은 대체로 맞다**. 노틸러스의 모래·갑판·바다, 커닝시티의 콘크리트·철로, 오르비스의 구름·별길, 니할 사막의 모래·유사처럼 지역을 식별할 핵심 소재는 존재한다.
- 그러나 맵 단위에서는 **단일 타일의 넓은 반복**, **평행선·사선 문양**, **지역 간 동일 지형 템플릿 재사용** 때문에 눈의 피로와 지역성 약화가 발생한다.
- `area_07`~`area_20` 112맵 중 109맵은 타일 인덱스를 지역별 역할로 정규화하면 같은 8종 공간 배치를 공유한다. 예외는 `r_077` 용암 균열, `r_085` 달빛 정원, `r_13a` 오아시스다.
- `area_01`의 일반 사냥방 `r_01`~`r_05`는 타일 배치가 완전히 동일하다.
- `area_00`·`area_05` 16맵 중 갑판 전용 `r_05a`를 제외한 15맵이 사선 모래 또는 사선 바다의 반복 영향을 받는다.

## 공통 검수 수치

- 지역 소속 맵: 159개(마을 제외)
- 일반 지역 맵: 157개, 모두 `RectTileMode=1`, 28×16=448칸
- 별도 소형 전직 맵: `mapjob`, `mapjob02`
- 타일셋 누락: 0개
- `area_07`~`area_20`의 기본 위험 지형 사용률:
  - `r_XX4`: 308/448칸 = 68.75%
  - `r_XX5`: 280/448칸 = 62.50%
  - `r_XX7`: 268/448칸 = 59.82%
- 따라서 네 번째 타일이 평행선·격자·단일 문양이면 카메라 화면 대부분이 반복 무늬가 된다.

## 기능상 즉시 교정할 항목

`area_07`~`area_10`의 기본 위험 타일은 타일셋에서 `IsCollidable=false`이며 맵에는 `NautilusWaterBoundary`가 붙어 있다. 그러나 이 스크립트의 기본 검사명은 `Nautilus_water`이고 각 맵에는 별도 이름 재정의가 없다.

실제 이름은 다음과 같다.

- `Sleepywood_chasm`
- `Orbis_sky_void`
- `ElNath_crevasse`
- `AquaRoad_deep_water`

따라서 네 지역에서 네 번째 타일을 사용하는 28맵은 현재 경계 스크립트가 해당 위험 지형을 감지하지 못한다. 시각 보정과 별개로 먼저 해결해야 한다. 신규 위험 변형을 만들 때도 이름 문자열 검사에 의존하지 말고 타일 충돌 속성 또는 명시적인 위험 타일 목록을 사용한다.

- ✅ 20지역 타일 원본·타일셋·159맵 사용량·공간 배치 전수 감사
- ⬜ P0: `area_07`~`area_10` 위험 타일 28맵의 실제 이동 차단 복구
- ⬜ P1: Area 00·05 모래/바다의 연속 사선 제거 및 표면 변형 확장
- ⬜ P1: Area 03의 사용되지 않는 흙길을 실제 동선에 반영하고 녹색 바닥 차별화
- ⬜ P1: `area_07`~`area_20`의 공용 8방 지형을 지역별 대표 구조로 차별화
- ⬜ P2: Area 01 일반 5방의 완전 동일 배치 해소
- ⬜ P2: Area 02 타일 원본을 Maker에서 확인하고 페리온 전용성 판정
- ⬜ P2: `mapjob02`를 엘리니아·보우마스터 테마로 차별화
- ⬜ P2: 각 지역 위험 지형에 중심·경계·희박 변형을 추가해 단일 문양의 50% 이상 화면 점유를 피함
- ⬜ 정적 검증: 모든 일반 맵 448칸, 포탈·스폰 안전 타일, 타일 RUID/인덱스, 충돌, 왕복 연결
- ⬜ Maker 검증: 대표방과 문제방에서 실제 화면 반복감·좌우 이동·위험 지형 충돌 확인

## 보정 원칙

1. 넓은 바닥은 최소 3개 변형을 사용한다.
2. 한 타일을 관통하는 고대비 평행선은 연속 배치를 금지하고 짧은 선·곡선·빈 공간으로 끊는다.
3. 동일한 강한 문양이 가로·세로 3칸 이상 이어지지 않게 한다.
4. 위험 지형은 기본면·경계면·강조면을 구분한다.
5. 지역별 대표방은 팔레트 교체가 아니라 길·섬·다리·공터·절벽 형태부터 다르게 설계한다.
6. 현재 지역을 잘 읽게 하는 핵심 타일과 T66 특수 타일은 보존한다.
7. 카메라가 실제로 보는 범위에서 반복도를 판단하고, 전체 28×16 배열만 보고 통과시키지 않는다.
